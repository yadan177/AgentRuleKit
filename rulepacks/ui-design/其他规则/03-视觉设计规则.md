# 03 - UI 视觉设计规则

> - 🟢 本文件适用于参考研究、视觉方向、布局、文字、色彩、图像、动效与平台适配。
> - 🔴 不适用：无依据套用固定风格、尺寸或品牌，或以效果图替代交互和设备验证。

---

## 1. 方向与参考

- 🔴 先理解用户任务、平台输入、内容与品牌约束，复用已有有效方向；新方向用少量可比样例说明取舍和实现成本。
- 🔴 参考区分官方规范、已发布产品实录、工具示例和概念稿。记录具体链接或文件、访问日期、画面与条件、借鉴点和不可迁移部分。
- 🔴 搜索摘要、概念图或宣传片不能证明可用性、运行性能或目标设备支持；无法读取原文时说明证据范围。
- 🔴 探索稿可使用注明性质的临时内容；未经采用的方向不覆盖正式变量、组件或资源。
- 🟡 新项目先形成必要颜色、文字、尺度与控件基础，再用真实代表页修订；已有项目的局部微调不重新发起整套风格探索。

## 2. 信息层级与布局

- 🔴 层级对应用户任务和信息重要性，当前状态与主要操作易于识别。
- 🔴 用对齐、接近、留白和对比组织信息，不依赖装饰框线解释所有关系。
- 🔴 说明固定、拉伸、重排、换行、截断、滚动与溢出行为，核对长文本、空值、加载和异常内容。
- 🔴 弹层、提示及高优先级信息与任务的遮挡、并存和阻断关系明确。
- 🟡 间距、网格、形状和材质使用可复用尺度，具体数值来自项目，不把某个参考页面的像素值提升为通用规则。

## 3. 文字与界面文案

- 🔴 字体家族、字重、行高、回退、文字覆盖与取得方式明确；按 [资源规则](./06-设计工具与切图导出规则.md) 选择系统字体、已有依赖或需交付文件，不统一要求复制字体二进制。
- 🔴 普通文字优先保留文本语义与运行时可控性，检查缩放、本地化、选择/辅助读取等项目需要；固定艺术字或插画标签的例外需有理由。
- 🔴 每段文案帮助识别对象、判断状态、完成操作、理解后果或恢复。标题、说明和按钮不换词重复同一信息。
- 🔴 不为填满模板增加欢迎语、副标题、技术细节或功能承诺。供开发与设计者阅读的解释留在设计文档。
- 🔴 简洁不能删除必要的错误原因、恢复方法、陌生概念解释和操作后果；不能以“越少越好”机械删字。
- 🔴 展示或交付前检查实际画面：删减冗余、保留必要内容，并复查间距、换行和面板尺寸。局部任务检查受影响区域即可。

❌ 反例：同一区域用标签、标题与正文三次重复“网络未连接”，却没有恢复方法。

✅ 正例：保留明确的离线状态、必要的检查建议和可执行操作，并按真实内容重新布局。

## 4. 色彩、图标与图片

- 🔴 色彩按语义使用，品牌、选择、成功、警告和危险分别判断；关键状态不能只依赖颜色差异。
- 🔴 核对真实背景、透明叠加、文字与关键边界的辨识度；适用的对比度要求按目标平台与项目标准核实。
- 🔴 图标有明确语义，风格、视重和对齐一致；可见图形与实际命中区分别定义。
- 🔴 图片说明比例、裁切焦点、加载失败和替代内容；叠字需要检查不同图片下的阅读条件。
- 🔴 字体、图标、照片和生成素材记录来源及使用条件；业务、科学或文字内容须核对，不能把参考素材自动作为可分发资源。
- 🟡 模糊、发光、透明和渐变依据任务需要与性能选择，并准备可行的降级表现。

## 5. 状态、动效与适配

- 🔴 按已采用交互模型表达焦点、选择、按压、禁用和业务状态，不为视觉完整感添加新业务。
- 🔴 动效说明触发、起止、时长依据、缓动、打断、循环及必要降级；不通过装饰动效拖慢高频任务。
- 🔴 响应式或跨尺寸设计说明内容如何变化，不只提供不同尺寸截图；按项目检查安全区、方向、缩放和输入。
- 🔴 系统键盘、权限、账号和导航等平台行为先核对实际集成，不用自制页面冒充系统流程。
- 🟡 可访问性要求贯穿内容、颜色、焦点、输入与运动，不只在完稿后检查色值。

## 6. XR 与空间界面

仅当任务涉及空间界面时应用：

- 🔴 识别 VR、透视 MR 或 AR 的目标显示方式、渲染与输入能力，不能从另一平台的案例推断已支持眼动、材质或窗口能力。
- 🔴 分别记录设计像素、物理尺寸、观看距离、角尺寸及映射依据，不把 px、dp、pt、米和角度直接互换。
- 🔴 核对可见尺寸、命中区、间距、锚定、遮挡、用户姿态及近距/远距输入；减少不必要的持续抬臂、追随或景深切换，并通过目标条件验证。
- 🔴 透明、模糊、跟随和层叠在明暗及复杂背景、双眼显示和目标性能条件下分别检查；没有实测时保留待验证。
- 🔴 桌面预览、设计原型、引擎运行和目标设备的可读性、舒适性与性能结论分别记录。

❌ 反例：把其他平台的按钮尺寸照搬成设计像素，凭平面截图认定头显内可读。

✅ 正例：说明单位和空间映射，在目标设备验证阅读、命中、遮挡与运动；当前未执行的部分明确列出。

## 7. 完成检查

- [ ] 方向、基础与正式页面之间有来源和采用依据。
- [ ] 内容层级、文案、极限长度、空值与异常经过实际画面检查。
- [ ] 状态与动效服务于已定义行为，适配与输入有明确条件。
- [ ] 素材与字体取得方式明确，运行时内容未被误烘焙。
- [ ] 平面、空间、实现与设备证据没有混写。
