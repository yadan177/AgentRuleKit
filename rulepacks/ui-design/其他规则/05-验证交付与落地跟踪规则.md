# 05 - UI 验证、交付与落地跟踪规则

> - 🟢 本文件适用于设计评审、原型验证、用户测试、交接、实现走查与设备验收。
> - 🔴 不适用：用静态截图、工具回执或设计采用记录代替实际验证。

---

## 1. 验证层级

先确定问题、对象版本、环境与通过条件，再选择方法。按本次任务执行，不要求每次文案修正都开展完整用户测试。

| 层级 | 能支持的结论 | 必须说明的限制 |
|---|---|---|
| 需求与设计检查 | 来源、流程、状态、布局与规则一致 | 不证明用户任务表现 |
| 原型或控制模拟 | 被模拟流程、状态转换与资源组合 | 不证明真实接口、原生输入或绑定 |
| 实现走查 | 实际构建下的内容、行为和绑定 | 记录构建、环境、数据与覆盖范围 |
| 目标设备验证 | 该设备和条件下的阅读、命中、运动与性能 | 不扩展到未测平台与场景 |
| 用户测试 | 指定样本和任务下的观察结果 | 说明样本、方法与推断边界 |

没有真实用户时可以做专家走查，但不能称为用户测试。观察、解释、建议与决定分别记录。

## 2. 设计评审

- 🔴 按需求核对主要路径、关键异常、返回、取消、中断及恢复，反查每项 UI 的触发与退出。
- 🔴 按控件与成员核对输入反馈、业务选中、连续值和组约束，避免只看整页状态截图。
- 🔴 实际画面检查文字层级、文案必要性、重复信息、长度极值、空值、适配和可访问性；删字后复查布局。
- 🔴 组件调整检查来源、变量、实例、原型和受影响消费者，不只验证被直接编辑的一个对象。
- 🔴 工具写入后检查页面归属、画布与图层顺序、边界和引用，方法见 [06](./06-设计工具与切图导出规则.md)。

## 3. 按实现方式交付

| 内容 | 交付要求 |
|---|---|
| 设计基线 | 可定位的文件、页面/节点、版本或变更记录与采用范围 |
| 交互与内容 | 流程、状态、动态内容、恢复、适配与动效契约 |
| 系统与组件 | 来源、必要属性与限制、已有代码组件映射 |
| 原生/样式/矢量实现 | 对应组件、样式或资源及使用条件，不补造位图底图 |
| 位图或混合实现 | 按已确定边界交付独立资源；需要时提供基准整图、静态底图与状态切图 |
| 字体 | 系统/已有依赖或需交付文件的取得方式、字重、覆盖和使用条件 |
| 跟踪记录 | 设计、资源、实现、验证各自的基线与缺口 |

- 🔴 标注只补开发无法可靠推断的规则，动态布局、状态和资源映射明确，不机械抄所有工具数值。
- 🔴 交付清单从需求与源稿反向核对，不能只检查导出文件是否符合 AI 自拟清单。
- 🔴 文档、设计源与素材按项目约定存放；清单在已有文档维护，不为每次导出重复生成 CSV、MD 或流程脚本。

## 4. 视觉还原与独立控制

### 4.1 视觉对照

按实际实现方式组装组件、样式、文本与资源，对照采用的设计基线，检查字体、布局、层级、边界和适配。位图状态资源检查相同画布与锚点、真实 Alpha 和透明留边；只有相关资源才执行这些检查。

### 4.2 控制检查

| 对象 | 验证动作 | 通过条件 |
|---|---|---|
| 独立成员 | 逐项操作或模拟业务更新 | 该项可控制，其他成员不意外改变 |
| 选择组 | 切换有效单选/多选组合 | 遵循组约束，选择值与焦点不混淆 |
| 内容与显隐 | 更换文字、数据及显示条件 | 动态内容没有烘焙进底图或其他控件 |
| 连续属性 | 检查起点、中间、终点和异常边界 | 范围、方向、终止和控制主体正确 |
| 状态切换 | 进入、退出与打断 | 反馈、恢复及几何变化符合定义 |

❌ 反例：三张整栏当前项截图能够还原画面，便声称三个独立选项的绑定已完成。

✅ 正例：逐项核对选择关系、资源或组件映射，实测有效组合；只做模拟时明确真实绑定尚未验证。

## 5. 实现差异与变更闭环

每个问题记录对象、设计与实现基线、现象、影响、证据、处理决定与状态。沿用项目已有缺陷等级，不另建冲突体系。

- 🔴 区分设计问题、实现错误、需求变化与平台限制；接受差异有理由和适用范围，不静默反写全局规范。
- 🔴 设计或组件变化时追踪页面、状态、资源、代码与验证记录；没有同步的消费者列为缺口。
- 🔴 删除前检查原型、实例、导出和工程引用。清理策略依据版本控制和任务授权，不默认归档全部旧资源。
- 🔴 未测设备、网络、性能或辅助输入保持未验证，不以一句“基本通过”掩盖条件。

## 6. 完成检查

- [ ] 交付与任务范围相符，设计、资源、实现和验证可分别定位。
- [ ] 主路径、必要状态、异常、文案与适配已按范围核对。
- [ ] 视觉对照和独立控制分别有结果；未执行的绑定或设备检查明确。
- [ ] 已修改的权威来源与消费者同步情况清楚。
- [ ] 文档、决定与未决问题已更新，没有重复清单和过程性产物混入正式资源。
