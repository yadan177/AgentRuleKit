# 03 - Python 异常处理规则

> 🟢 本文件适用于 Python 的异常定义、捕获、转换、重试和清理。
> 🔴 不适用：吞掉异常、伪造成功结果，或把所有错误统一转换为模糊异常。

---

## 1. 异常边界

- 🔴 只捕获能够处理、转换或补充上下文的异常；否则让异常向上冒泡。
- 🔴 `except Exception` 只允许位于明确的进程、任务或请求边界，并且必须记录上下文、清理资源或转换为已定义错误。
- 🔴 禁止裸 `except:`，除非在顶层清理 `BaseException` 的极少数场景且有明确理由。
- 🔴 异常转换时保留原因链，使用 `raise NewError(...) from exc`。

## 2. 重试与清理

- 🔴 仅对可恢复、幂等且已确认的故障重试；设置次数、超时、退避和终止条件。
- 🔴 在 `finally` 或上下文管理器中释放资源；不能依赖垃圾回收时机。
- 🟡 业务异常与基础设施异常分层表达，避免调用方依赖字符串匹配判断错误类型。

## 3. 示例

```python
try:
    payload = client.fetch(user_id)
except TimeoutError as exc:
    raise UpstreamUnavailable("user service timed out") from exc
```
