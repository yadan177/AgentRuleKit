# 07 - Python 数据访问规则

> 🟢 本文件适用于数据库、缓存、文件存储、迁移和持久化代码。
> 🔴 不适用：默认选择 ORM、数据库、迁移工具或缓存产品。

---

## 1. 数据边界

- 🔴 沿用项目已有的数据访问层、模型映射、连接管理和迁移流程。
- 🔴 SQL、查询构造和过滤条件必须参数化；禁止拼接外部输入形成查询、路径或命令。
- 🔴 事务范围最小且明确：写清开始、提交、回滚和异常处理责任。

## 2. 迁移与兼容

- 🔴 schema 变化必须通过项目已有迁移机制管理；禁止仅修改模型而不处理已有数据。
- 🔴 线上兼容性、索引、默认值、回填和回滚方案需在变更前确认。
- 🟡 大批量读写、分页、连接池和缓存失效策略先测量或参考已有实现，再优化。

## 3. 敏感数据

- 🟠 数据访问日志、异常和测试夹具不得泄露密码、令牌、个人数据或生产数据。
- 🟠 权限过滤必须在可信数据边界完成，不能只依赖前端或调用方传入的范围。
