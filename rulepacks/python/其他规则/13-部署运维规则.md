# 13 - Python 部署运维规则

> - 🟢 本文件适用于 Python 项目的环境、构建、依赖、迁移、启动、监控和回滚。
> - 🔴 不适用：未经授权修改生产配置、执行迁移、发布或回滚。

---

## 1. 环境与构建

- 🔴 部署使用项目声明的 Python 版本、依赖锁定方式、构建脚本和启动命令。
- 🔴 配置通过项目既有的环境变量、配置文件或密钥系统注入；不得把生产值硬编码进镜像或源码。
- 🔴 容器、进程管理、Web server 和任务 worker 沿用项目已有方案，不默认选择 Gunicorn、Uvicorn、Docker 或 Kubernetes。

## 2. 发布与迁移

- 🔴 发布前确认版本、依赖、配置、迁移、健康检查、回滚和审批要求。
- 🔴 数据迁移必须有项目批准的执行顺序、兼容窗口和失败处理；禁止把不可逆迁移混入未验证发布。
- 🟡 发布后按项目指标检查错误率、延迟、队列积压、资源使用和关键业务路径。

## 3. 运行与故障处理

- 🔴 健康检查、优雅关闭、超时、重试和后台任务退出语义遵循项目运行模型。
- 🔴 故障操作先保存证据并遵循权限与升级流程；不得直接修改生产数据掩盖问题。
- 🟡 运行手册记录前置条件、操作、预期结果、失败处理和回滚路径。
