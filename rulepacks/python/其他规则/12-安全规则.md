# 12 - Python 安全规则

> 🟢 本文件适用于 Python 项目的输入、认证、授权、密钥、依赖、序列化和数据处理。> 🟠 不适用：以开发便利为由绕过权限、校验、审计或密钥管理。

---

## 1. 输入与执行

- 🟠 所有外部输入在可信边界验证类型、范围、长度、格式和权限。
- 🟠 数据库查询、路径、模板、正则、命令和动态导入不得直接拼接外部输入。
- 🟠 禁止对不可信数据使用 `eval`、`exec`、不安全反序列化或 `pickle`；YAML 等格式必须使用项目批准的安全加载方式。

## 2. 认证、授权与密钥

- 🟠 认证、授权和资源范围校验必须在服务端可信边界执行。
- 🟠 密钥、令牌和连接串从项目批准的配置或密钥管理系统获取，不写入源码、日志、测试夹具或文档。
- 🟠 密码使用项目批准的专用哈希和验证机制，禁止自创加密、哈希或令牌算法。

## 3. 依赖与运行环境

- 🟠 新依赖前检查项目安全流程、维护状态和许可证；发现高风险漏洞按项目流程处理。
- 🔴 生产错误响应和日志不得暴露堆栈、内部路径、配置或敏感数据。
- 🟡 需要文件上传、网络请求或后台任务时，明确大小、类型、超时、重试和资源限制。
