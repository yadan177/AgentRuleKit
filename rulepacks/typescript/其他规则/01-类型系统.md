# 01 - TypeScript 类型系统

> - 🟢 本文件适用于 TypeScript 类型层硬约束（type vs interface/any/unknown/工具类型）。
> - 🔴 不适用：业务逻辑实现、UI 样式设计

---

## 1. 🔴 硬约束 · 这些绝对不要写

### 1.1 type vs interface 选型

```ts
// ✅ interface：对象 / 类的形状(可继承 / 可声明合并)
interface User {
  id: number;
  name: string;
}
interface AdminUser extends User {
  role: 'admin';
}

// ✅ type：联合 / 交叉 / 工具类型 / 计算属性
type Status = 'pending' | 'approved' | 'rejected';
type UserOrError = User | { error: string };
type ReadonlyUser = Readonly<User>;
type Getters<T> = { [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K] };
```

**经验法则**：

| 场景 | 选谁 |
|------|------|
| 对象 / 类的形状（可继承 / 合并） | `interface` |
| 联合 / 交叉类型 | `type` |
| 工具类型（`Partial<T>` 之类） | `type` |
| 需要声明合并（多次 `interface Foo`） | `interface` |
| 元组 / 数组具体形状 | `type` |
| 计算属性 / 映射类型 | `type` |

### 1.2 any 滥用（关闭类型检查）

```ts
// ❌
function parse(input: any) { return JSON.parse(input); }
const data: any = fetchUser();

// ✅ unknown 替代，并在外部数据边界执行运行时校验
function parse(input: unknown): User {
  if (typeof input !== 'string') throw new Error('Expected string');
  const value: unknown = JSON.parse(input);
  if (!isUser(value)) throw new Error('Invalid user payload');
  return value;
}
```

项目已经采用 typescript-eslint 且现有配置允许时，可以评估下列规则；启用范围和严重级别必须沿用项目门禁，不得因本示例新增或替换 lint 工具链：

```js
// eslint.config.js
{
  rules: {
    '@typescript-eslint/no-explicit-any': 'error',
    '@typescript-eslint/no-unsafe-assignment': 'error',
    '@typescript-eslint/no-unsafe-call': 'error',
    '@typescript-eslint/no-unsafe-member-access': 'error',
    '@typescript-eslint/no-unsafe-return': 'error',
  },
}
```

### 1.3 unknown 没有收窄就用

```ts
// ❌
function process(input: unknown) {
  return input.name;                       // ❌ 编译报错(unknown 无属性)
}

// ✅ 收窄
function process(input: unknown) {
  if (typeof input === 'object' && input !== null && 'name' in input) {
    return (input as { name: string }).name;
  }
  throw new Error('Invalid input');
}

// 项目已经采用 zod 时可复用其运行时校验
import { z } from 'zod';
const UserSchema = z.object({ name: z.string() });
const user = UserSchema.parse(input);      // 类型自动推断为 { name: string }
```

详见 [02-类型守卫与收窄](./02-类型守卫与收窄.md)。

### 1.4 enum 滥用

```ts
// ⚠️ 数字 enum 会产生运行时代码和反向映射，是否适合取决于协议与项目版本
enum Color { Red, Green, Blue }

// ⚠️ const enum 与部分 isolatedModules/发布链不兼容，库代码尤其要谨慎
const enum Direction { Up, Down }

// ✅ 用 as const 对象字面量
const Color = {
  Red: 'red',
  Green: 'green',
  Blue: 'blue',
} as const;
type Color = typeof Color[keyof typeof Color];     // 'red' | 'green' | 'blue'
```

**enum 也不是完全禁用**——字符串 enum 在某些场景仍可用：

```ts
// ✅ 字符串 enum(明确枚举名 + 字符串值)
enum HttpStatus {
  OK = 'OK',
  NotFound = 'NOT_FOUND',
  ServerError = 'SERVER_ERROR',
}
```

`as const` 对象、字符串联合和字符串 enum 都有合理场景；沿用项目的序列化、反向映射、运行时产物和公开 API 约定，不设统一默认。

### 1.5 联合类型误用（不会收窄）

```ts
// ❌ 没法区分的 union
type Shape = { width: number } | { height: number };
function area(s: Shape) {
  return s.width * s.height;               // ❌ 两个都没有两个属性
}

// ✅ 判别联合(discriminated union)
type Shape =
  | { kind: 'rect'; width: number; height: number }
  | { kind: 'circle'; radius: number };
function area(s: Shape): number {
  switch (s.kind) {
    case 'rect': return s.width * s.height;
    case 'circle': return Math.PI * s.radius ** 2;
  }
}
```

### 1.6 泛型滥用（应为具体类型）

```ts
// ❌ 写两个泛型只用一个
function identity<T, U>(x: T, _y: U): T { return x; }

// ✅ 一个泛型解决
function identity<T>(x: T): T { return x; }

// ✅ 用泛型约束
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}
```

### 1.7 工具类型选择不当

```ts
// ❌ 自己造轮子
type MyPartial<T> = { [K in keyof T]?: T[K] };   // 与 Partial 重复

// ✅ 用内置
type UserOptional = Partial<User>;
type UserNameOnly = Pick<User, 'name'>;
type UserWithoutPassword = Omit<User, 'password'>;
type UserReadonly = Readonly<User>;
```

**常用工具类型**：

| 类型 | 作用 |
|------|------|
| `Partial<T>` | 全字段可选 |
| `Required<T>` | 全字段必填 |
| `Readonly<T>` | 全字段只读 |
| `Pick<T, K>` | 选字段 |
| `Omit<T, K>` | 去字段 |
| `Record<K, V>` | key-value 映射 |
| `Exclude<T, U>` | 从 T 排除 U |
| `Extract<T, U>` | 从 T 提取 U |
| `ReturnType<T>` | 函数返回类型 |
| `Parameters<T>` | 函数参数元组 |
| `Awaited<T>` | Promise 解包 |

## 2. 🟡 推荐 · 团队约定

### 2.1 命名约定（type / interface）

```ts
// ✅ interface 不加 I 前缀
interface User {}                       // 推荐
interface IUser {}                      // 不推荐(C# 风格)

// ✅ type 别名 PascalCase
type UserId = string;
type Status = 'pending' | 'done';

// ✅ 泛型用单字母
function identity<T>(x: T): T { return x; }
function merge<A, B>(a: A, b: B): A & B { return { ...a, ...b }; }

// 复杂场景可用描述性名字
function fetchEntity<Entity extends { id: string }>(id: string): Promise<Entity> { /* ... */ }
```

### 2.2 导出风格

**具名导出优先**（与 [01-代码编写规则 §7](../../javascript/其他规则/01-代码编写规则.md) 一致）：

```ts
// ✅
export interface User {}
export function getUser(id: number) {}

// ❌ 默认导出整个对象
export default { User, getUser };
```

### 2.3 字面量类型与 `as const`

```ts
// ❌ 反复声明字面量类型
const direction: 'up' | 'down' = 'up';

// ✅ 用 as const 一次搞定
const direction = 'up' as const;

// ✅ 字面量对象
const CONFIG = {
  apiUrl: 'https://api.example.com',
  timeout: 5000,
} as const;
type Config = typeof CONFIG;            // { readonly apiUrl: 'https://...'; readonly timeout: 5000 }
```

### 2.4 公共 API 显式返回类型

```ts
// ✅ 公共函数显式返回类型(库代码)
export function getUser(id: number): Promise<User | null> { /* ... */ }

// ✅ 业务代码可依赖推断(更简洁)
const sum = (a: number, b: number) => a + b;     // TS 推断为 (a: number, b: number) => number
```

## 3. 🟢 可选 · 视情况

### 3.1 satisfies 运算符（TS 4.9+）

```ts
// ✅ 校验形状 + 保留字面量推断
const colors = {
  red: '#f00',
  green: '#0f0',
} as const satisfies Record<string, string>;

colors.red;                              // 类型是 '#f00'(不是 string)
```

**vs `as`**：
- `satisfies`：校验形状 + 保留窄类型
- `as`：强制断言类型（**最后手段**）

### 3.2 const 类型参数（TS 5.0+）

```ts
// const 类型参数适合在泛型 API 边界保留调用方字面量信息
function defineRoutes<const T extends readonly string[]>(routes: T): T {
  return routes;
}

const routes = defineRoutes(['/users', '/orders']);
// typeof routes 是 readonly ['/users', '/orders']
```

### 3.3 模板字面量类型

```ts
type EventName = `on${Capitalize<string>}`;       // 'onClick' | 'onHover' | ...
type ApiPath = `/api/${string}`;                  // 路径约束
```
