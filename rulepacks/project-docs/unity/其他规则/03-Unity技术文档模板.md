# 03 - Unity 技术文档模板

> - 🟢 本文件适用于建立或完善 Unity 技术文档与 Code Wiki。
> - 🔴 不适用：填充无证据内容、保留空章节或为了套模板重复已有文档。

---

## 1. 选择模板与通用元数据

- 🔴 先按 [任务入口](./04-UnityAI技术文档任务入口.md) 理解范围内的代码，再按 [组织规范](./01-技术文档组织与维护规范.md) 更新已有文档或选择模板。
- 🔴 按读者问题和项目规模选择内容；一个模板不等于必须创建一个文件。移除不适用章节，替换占位符，复用已有来源和链接。
- 🔴 除索引外，正文按组织规范使用以下元数据或项目已有等价机制；模板中的状态与示例不能直接当作验证结论。

```markdown
---
标题: <标题>
创建日期: YYYY-MM-DD
负责人: <已有负责人、团队或责任角色；无法确认时草稿标待确认>
状态: 草稿
最后更新: YYYY-MM-DD
关联文档: [<项目内相对路径>]
来源: [<相对路径与稳定符号、配置或验证记录>]
---

# <标题>
```

以下正文模板使用前添加适用的元数据，不必重复粘贴无关模板。

## 2. README 阅读导航与覆盖关系

根索引导航主要读者任务；主题索引只保留本主题所需入口。已有覆盖矩阵时直接链接，不再维护第二份。

```markdown
# 技术文档

范围：<本次覆盖的仓库、子系统与未覆盖内容>

| 我想了解 | 阅读入口 |
|---|---|
| 项目技术全貌 | [技术总览](./<实际路径>.md) |
| 首次运行 | [新人上手](./<实际路径>.md) |
| 修改或排查某项功能 | <模块、链路及验证文档入口> |

| 主要能力/模块 | 源码或资源入口 | 文档入口 | 验证状态/缺口 |
|---|---|---|---|
| <能力> | `<路径与入口符号>` | <对应正文链接> | <已核查、实测范围或未覆盖原因> |
```

## 5. 系统架构与关键链路模板
