# 03 - Python 技术文档模板

> 🟢 本文件适用于创建 Python 技术文档。<br>
> 🔴 不适用：保留空章节、填充无证据内容或为了套模板重复已有文档。

---

## 1. 通用元数据

```markdown
---
标题: <标题>
创建日期: YYYY-MM-DD
负责人: <负责人、团队或责任角色；无法确认时临时填待确认>
状态: 草稿
最后更新: YYYY-MM-DD
关联文档: [<项目内相对路径>]
来源: [<代码符号、配置、契约或测试记录>]
---

# <标题>
```

## 2. 技术主题目录模板

主题目录只在存在真实正文时创建，`README.md` 只做导航，不填写元数据：

```markdown
# <技术主题>

| 文档 | 说明 | 状态 | 负责人 |
|---|---|---|---|
| [<中文主题>](./<中文主题>.md) | <一句话说明> | 有效 | <负责人> |
```

技术主题可持续扩展：

```text
技术文档/
├── 02-架构与工程/
│   ├── README.md
│   ├── 系统架构.md
│   └── 构建与环境.md
└── 06-运行维护/
    ├── README.md
    ├── 发布流程.md
    └── 故障排查.md
```

## 3. 新人上手模板

```markdown

|---|---|---|
| Python / 包管理器 / 权限 | <版本或条件> | `pyproject.toml` 或团队入口 |

## 常见问题与求助入口

## 关联文档与变更记录
```

```markdown
| 模块/组件 | 负责什么 | 不负责什么 | 来源 |

```

## 5. 契约、测试、运行与 ADR 模板

```markdown
# <主题名称>

## 概述与权威来源

## 契约/验证/操作内容

| 项目 | 方法或约束 | 通过标准/预期结果 | 来源 |
|---|---|---|---|
| <接口、测试或步骤> | <说明> | <结果> | `<路径或符号>` |

## 兼容性、失败处理与限制

## 文档变更记录
```

ADR 额外保留“背景与问题、决定与依据、替代方案与后果、复查条件”。
