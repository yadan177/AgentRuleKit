桌面应用 1.1.0 会在启动时检查软件版本；仅发现新版时显示顶部提示。Mac 点击提示后下载 DMG，再由用户手动替换旧版；Windows 点击提示后下载 EXE，关闭旧版并运行安装包。项目规则更新仍需逐文件审查并确认。

安装项目规则时，生成的 `AGENTS.md` 会明确引导 AI 读取项目覆盖规则、通用入口和当前任务对应的开发或文档规则，并在规则缺失时说明情况。

从没有软件更新功能的 1.0.0 升级到 1.1.0，需要手动下载并安装一次。本版 Mac 和 Windows 均为手动安装；Windows 安装包未签名，系统可能提示未知发布者，软件不会在应用内自动安装。macOS 提供 Apple Silicon 安装包，Windows 提供 x64 安装包。
