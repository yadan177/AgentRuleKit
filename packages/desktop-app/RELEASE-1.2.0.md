桌面版 1.2.0 新增“插件与 Skills”模块和项目列表。

- 自由导入本机插件包或独立 Skill，选择目标软件后预览安装；不按技术栈强制分组，不绑定业务项目。
- Codex 支持独立 Skill 和原生插件。插件通过官方 Codex CLI 安装，已完成隔离环境的安装、更新、卸载和宿主识别检查。找不到支持的 CLI 时会提示处理，不自动改动 Codex。
- 已安装内容可选择新版本，预览后更新或卸载。未知文件、受管内容漂移、符号链接和过期预览会阻止覆盖。
- 项目列表保存本机项目路径，方便分别管理各项目规则；“移出列表”保留项目文件。
- TraeWork 本地 Skill 交付为**实验支持**，包括独立 Skill 和 Product Design 0.1.56 入口适配。安装文件流程已检查，客户端识别和实际任务仍待验收；不支持通用原生插件、云端同步或新 TRAE 兼容。

本版验收针对安装器的文件和注册流程。第三方插件的工具连接、Hook 信任、Skill 实际任务效果仍须在目标软件验证。应用不附带第三方插件正文，导入来源和许可由用户查看。

macOS 提供 Apple Silicon DMG，Windows 提供 x64 EXE。两个平台均提示下载后手动安装；安装包未签名，Mac 包未公证。Windows 真实桌面交互仍待验收。桌面版独立升级，npm CLI 和规则包仍为 0.1.5。
