# 00 - Go 技术文档规则适配器使用说明

---

## 1. 使用目标

本目录提供 Go 技术文档规则正文和编辑器入口。`AGENTS.md` 只属于 Codex；Qoder、TRAE 和其他编辑器必须使用各自已验证的入口形式。

Go 开发规则和技术文档规则共同使用时，必须同时安装两个入口：开发入口负责在实现任务开始前触发文档影响判断，技术文档入口负责具体同步；两者不能相互覆盖或只安装其一。

## 2. 文件映射与安装

| 源内容 | 目标位置 |
|---|---|
| `其他规则/` 下的 `00` 至 `04` | `.ai-rules/go-project-docs/其他规则/` |
| `codex/AGENTS.md` | 合并到项目根 `AGENTS.md` |
| `qoder/.qoder/rules/go-project-docs.md` | `.qoder/rules/go-project-docs.md` 并设为始终生效 |
| `trae/00-TRAE手动使用Go技术文档规则说明.md` | 按说明在相关任务中手动附加 |

安装顺序：先复制正文，再安装当前编辑器入口，最后执行文件、编辑器和行为三层验证。仅复制正文不算完成安装。

## 3. 验证

- 🔴 文件检查：`00` 至 `04` 和入口引用路径必须存在。
- 🔴 编辑器检查：Codex 入口处于当前作用域；Qoder 入口已设为始终生效；TRAE 已为当前任务手动附加。
- 🔴 行为检查：最小任务必须输出已加载入口、文档影响结论和判断依据。

## 4. 更新与维护

- 🔴 适配器只保留简短触发条件和路由，不复制完整专题正文。
- 🔴 项目级入口必须同时覆盖明确的技术文档任务和实现任务触发的文档影响同步；不得只在用户说“写文档”时加载。
- 🔴 当前没有适配器的编辑器，必须先确认其稳定规则格式再新增，禁止直接照搬 Codex 的 `AGENTS.md`。
- 🔴 更新 Codex 入口时合并而非覆盖；更新 Qoder 后复核始终生效状态；更新 TRAE 后重新附加。
- 🔴 路径、文件名或调用链变化后重新执行三层验证。
- 🔴 移动 `04-GoAI技术文档任务入口.md` 或专题文件时，更新全部适配器路径。
