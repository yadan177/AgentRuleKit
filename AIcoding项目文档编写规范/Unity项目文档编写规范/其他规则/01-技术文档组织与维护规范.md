# 01 - 技术文档组织与维护规范

> 🟢 本文件适用于 Unity 技术文档的目录、索引、命名、元数据和生命周期。<br>
> 🔴 不适用：策划、美术、制作、运营或管理文档的组织与维护。

---

## 1. 推荐目录

技术文档是唯一受本规则库管理的项目文档。它可放在仓库的 `项目文档/`技术文档/（如果没有创建一下）或团队既有位置；不要求为套用本规则迁移稳定的历史路径。

```text
技术文档/
├── README.md
├── 00-新人上手.md
├── 01-技术总览.md
├── 02-架构与工程/
├── 03-模块设计/
├── 04-接口与数据/
├── 05-测试与质量/              # 有独立测试维护需求时创建
├── 06-运行维护/
└── 07-架构决策记录/
```

| 位置 | 回答的问题 | 典型内容 |
|---|---|---|
| `README.md` | 去哪里找 | 文档索引、状态、owner |
| `00-新人上手.md` | 如何开始工作 | 环境、运行、验证、常见问题、求助入口 |
| `01-技术总览.md` | 项目技术全貌是什么 | Unity/包版本、架构地图、关键入口、术语 |
| `02-架构与工程/` | 工程如何组织 | 程序集、目录、依赖、资源和配置入口 |
| `03-模块设计/` | 某功能如何实现 | 职责、流程、边界、生命周期、验证 |
| `04-接口与数据/` | 模块如何交换数据 | 协议、存档、schema、版本兼容 |
| `05-测试与质量/` | 如何验证质量 | 测试策略、测试环境、质量门禁、性能基线 |
| `06-运行维护/` | 如何构建、发布和排障 | 构建、资源流程、监控、恢复、排障手册 |
| `07-架构决策记录/` | 为什么这样设计 | ADR 和替代方案 |

- 🔴 `00-新人上手.md` 必须放在技术文档根目录，不再归入管理流程。
- 🔴 `05-测试与质量/` 仅在测试资料有独立 owner、独立更新节奏，或达到 3 篇以上时创建；否则把测试要求放在模块或运行维护文档中。
- 🔴 不新增“策划”“美术”“管理”“代码规范”等目录；代码规范由独立的 AI 编程规则库维护。
- 🟡 性能、安全、网络和资源等横向主题，按问题归入架构与工程、接口与数据、测试与质量或运行维护，不为每个关键词单独建目录。

## 2. 索引、命名与链接

每个含正文的目录必须有 `README.md`，只负责导航，不承载长篇说明。

```markdown
# <目录名称>

> 范围：<本目录解决的问题>

| 文档 | 说明 | 状态 | Owner |
|---|---|---|---|
| [<标题>](./<文件名>.md) | <一句话说明> | active | <负责人> |
```

- 🔴 创建、移动、重命名或废弃文档后，必须更新最近一级 `README.md`。
- 🔴 文件和目录使用简短、可搜索的中文名称；`README.md` 保持工具约定名称。
- 🔴 文件名不带日期、版本号、“最终版”或“新版”；历史由 Git 管理。
- 🔴 引用必须给出具体路径、标题或代码符号，禁止只写“见代码”“见相关文档”。
- 🟡 跨文档术语统一登记在 `01-技术总览.md` 的术语区；不另建空的术语目录。

## 3. 元数据与状态

除 `README.md` 外，技术文档必须在文件开头包含以下 frontmatter；目标项目已有等价机制时可沿用。

```yaml
---
title: <标题>
owner: <负责人或待确认>
status: draft | active | deprecated
last_updated: <YYYY-MM-DD>
related: [<项目内相对路径>]
sources: [<代码符号、配置路径、契约或测试记录>]
---
```

- 🔴 `draft` 必须写明待确认事项；`active` 只记录当前有效事实；`deprecated` 必须说明替代路径。
- 🔴 实质修改后更新 `last_updated`；纯排版和错字修正可不更新。
- 🟡 `active` 超过 90 天未更新时由 owner 复查，不因时间自动判定失效。

## 4. 拆分、合并与废弃

满足“独立 owner/更新节奏”“被多篇文档复用”“一篇回答了多个无关问题”之一时拆分。只有一两段、不会复用或只是预期需求时不拆分。

创建、移动、合并或废弃文档时，依次完成：

1. 搜索同主题文档和权威来源。
2. 选择目录和模板，填写元数据。
3. 更新 `README.md`、关联链接和术语。
4. 校验链接、来源、状态和变更记录。
5. 废弃时保留原文、写明原因和替代路径，不直接删除。
