# 03 - Unity 技术文档模板

> 🟢 本文件适用于创建 Unity 技术文档。<br>
> 🔴 不适用：保留空章节、填充无证据内容或为了套模板重复已有文档。

---

## 1. 使用规则

- 🔴 创建前先搜索同主题文档，并按 [01 - 技术文档组织与维护规范](./01-技术文档组织与维护规范.md) 选择既有技术主题或新增主题。
- 🔴 使用最接近的模板；不适用章节删除或明确写“不适用及原因”。
- 🔴 所有正文保留用途、来源、边界、验证和变更记录信息。
- 🟡 简单主题可合并短章节；复杂关系再补 Mermaid 图。

## 2. 通用元数据与索引

### 2.1 技术正文元数据

```markdown
---
标题: <标题>
创建日期: YYYY-MM-DD
负责人: 待确认
状态: 草稿
最后更新: YYYY-MM-DD
关联文档: [<项目内相对路径>]
来源: [<代码符号、配置路径、契约或测试记录>]
---

# <标题>
```

### 2.2 README 索引

```markdown
# <目录名称>

> 范围：<本目录解决的问题>

| 文档 | 说明 | 状态 | 负责人 |
|---|---|---|---|
| [<标题>](./<文件名>.md) | <一句话说明> | 有效 | <负责人> |
```

### 2.3 技术主题目录

主题目录只在存在真实正文时创建，`README.md` 只做导航，不填写元数据；`02` 至 `07` 可按维护需要扩展子文档：

```text
技术文档/
├── 02-架构与工程/
│   ├── README.md
│   ├── 系统架构.md
│   └── 构建与环境.md
└── 06-运行维护/
    ├── README.md
    ├── 发布流程.md
    └── 故障排查.md
```
