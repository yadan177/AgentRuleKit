## 1. 使用要求

将本规则设为始终生效。执行 Unity 技术文档任务前，读取 `.ai-rules/unity-project-docs/其他规则/04-UnityAI技术文档任务入口.md`，再按总览选择专题规则。

## 2. 执行约束

- 🔴 必须检查 Unity 版本、包配置、程序集、Scene、Prefab、资源、构建和平台事实。
- 🔴 必须复用项目已验证的术语与权威来源；不确定时标记待确认或询问用户。
- ❌ 禁止臆造资源系统、XR、联机、设备、命令或验证结果。
