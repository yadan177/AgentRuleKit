# 00 - Unity 技术文档规则适配器使用说明

---

## 1. 使用目标

本目录为 Codex、Qoder 与 TRAE 提供 Unity 技术文档规则的薄入口。完整规则只维护在 `其他规则/` 下的 `00` 至 `04` 规则文件中，不得在适配器中复制专题正文。

## 2. 目标项目结构

```text
<unity-project>/
├── .ai-rules/unity-project-docs/
│   └── 其他规则/                       # 复制本目录的 00–04 技术文档规则文件
├── AGENTS.md                          # 合并 Codex 入口，不覆盖既有规则
└── .qoder/rules/unity-project-docs.md # Qoder 入口
```

## 3. 安装与维护

- 🔴 Codex：将 `其他规则/` 下的 `00` 至 `04` 技术文档规则文件复制到 `.ai-rules/unity-project-docs/其他规则/` 后，再将 `codex/AGENTS.md` 内容合并到项目根 `AGENTS.md`。
- 🔴 Qoder：复制 `qoder/.qoder/` 内容到目标项目并按当前版本设为始终生效。
- 🔴 TRAE：按[TRAE 手动使用 Unity 技术文档规则说明](./trae/00-TRAE手动使用Unity技术文档规则说明.md)手动附加，不猜测配置路径。
- 🔴 移动 `04-UnityAI技术文档任务入口.md` 或专题文件时，必须更新全部适配器路径。
