# 00 - Java 技术文档规则适配器使用说明

---

## 1. 使用目标

本目录提供 Java 技术文档规则正文和编辑器入口。Java 开发规则和技术文档规则共同使用时，必须同时安装两个入口：开发入口负责触发文档影响判断，文档入口负责具体同步；两者不能相互覆盖。

## 2. 文件映射与安装

| 源内容 | 目标位置 |
|---|---|
| `其他规则/` 下 `00` 至 `04` | `.ai-rules/java-project-docs/其他规则/` |
| `codex/AGENTS.md` | 合并到项目根 `AGENTS.md` |
| `qoder/.qoder/rules/java-project-docs.md` | `.qoder/rules/java-project-docs.md` 并设为始终生效 |
| TRAE 使用说明 | 在相关任务中手动附加 |

先复制正文，再只安装当前编辑器入口；最后执行文件、编辑器和行为三层验证。

## 3. 验证与维护

- 🔴 检查 `00` 至 `04`、入口引用路径和编辑器作用域。
- 🔴 最小任务必须输出已加载入口、文档影响结论和依据。
- 🔴 项目入口同时覆盖明确文档任务和实现任务触发的同步，不得只在用户说“写文档”时加载。
- 🔴 Codex 入口合并而非覆盖；Qoder 更新后复核始终生效；TRAE 更新后重新附加。
- 🔴 移动入口或专题文件时更新全部适配器路径并重新验证。
