# 03 - Java 技术文档模板

> 🟢 本文件适用于创建 Java 技术文档。<br>
> 🔴 不适用：保留空章节、填充无证据内容或为了套模板重复已有文档。

---

## 1. 通用元数据

```markdown
---
title: <标题>
owner: 待确认
status: draft
last_updated: YYYY-MM-DD
related: [<项目内相对路径>]
sources: [<代码符号、配置、契约或测试记录>]
---

# <标题>
```

## 2. 新人上手模板

```markdown
# 新人上手

## 环境与权限

| 项目 | 要求 | 来源/确认方式 |
|---|---|---|
| JDK / 构建工具 / 权限 | <版本或条件> | `<构建文件或团队入口>` |

## 首次运行与验证

1. <操作>
2. <预期结果>

## 常见问题与求助入口

## 关联文档与变更记录
```

## 3. 架构与模块模板

```markdown
# <主题名称>

## 概述

- 目标读者：<角色>
- 解决的问题：<问题>
- 不覆盖：<边界>

## 范围与来源

## 模块职责与依赖

| 模块/组件 | 负责什么 | 不负责什么 | 来源 |
|---|---|---|---|
| `<包、类或模块>` | <职责> | <边界> | `<路径>` |

## 关键流程、事务与资源边界

## 决策、限制与验证

## 文档变更记录
```

## 4. 契约、测试、运行与 ADR 模板

```markdown
# <主题名称>

## 概述与权威来源

## 契约/验证/操作内容

| 项目 | 方法或约束 | 通过标准/预期结果 | 来源 |
|---|---|---|---|
| <接口、测试或步骤> | <说明> | <结果> | `<路径或符号>` |

## 兼容性、失败处理与限制

## 文档变更记录
```

ADR 额外保留“背景与问题、决定与依据、替代方案与后果、复查条件”。
