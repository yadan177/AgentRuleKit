# 04 - Java AI 技术文档任务入口

> 🟢 本文件适用于 AI 创建、修改、审查和同步 Java 技术文档。<br>
> 🔴 不适用：臆造项目事实、伪造验证，或擅自升级 JDK、依赖、框架和构建系统。

---

## 1. 开始前

1. 阅读目标项目的 `AGENTS.md`、贡献指南和已有技术文档。
2. 搜索同主题文档、`README.md`、技术总览和 ADR，避免重复。
3. 检查相关构建文件、源码、配置、迁移、契约、测试、部署和 CI 事实。
4. 确认来源、读者、状态和 owner；缺失时标记待确认或询问。
5. 选择最小合适目录和模板，不为一次性内容建空目录。

## 2. 创建、更新与同步

- 🔴 已有文档足够覆盖时优先更新；否则按模板新建。
- 🔴 AI 无法确认 owner 时填写 `待确认`，初稿必须为 `draft`。
- 🔴 更新 `README.md`、关联链接和术语区。
- 🔴 代码、配置、迁移、契约、依赖或运行流程变更使 `active` 文档失真时，同步更新受影响内容；无法确认时报告差异。
- 🔴 文档被替代时改为 `deprecated`，保留原因与替代路径。

## 3. 交付

交付时说明修改内容及依据、已执行校验、未验证范围与风险，以及需要同步的其他技术文档。
