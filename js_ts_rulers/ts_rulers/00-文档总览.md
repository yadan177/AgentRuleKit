# 00 - TypeScript 专题规则总览

> 🟢 本文件适用于项目已使用 TypeScript 的类型、编译配置、声明与类型化工具链专题规则。

> 🔴 不适用：把 TypeScript 当作运行时安全保障、强制将 JavaScript 项目迁移为 TS，或替代上层 [JS/TS 通用入口规则](../01-AI通用入口规则.md)。

## 1. 使用方式

先遵守 [01 - JS/TS AI 通用入口规则](../01-AI通用入口规则.md)，读取 [JS 专题总览](../js_rulers/00-文档总览.md) 中的运行时基线，再按本表选择 TS 专题；交付前使用 [JS/TS AI 交付前自检](../02-AI交付前自检.md)。

🔴 **必须**：`tsconfig*.json`、实际 TypeScript 版本、构建器、生成代码、公开 API 和现有类型约定优先于本目录示例；不得为套用规则升级 TypeScript 或批量修改严格度。

## 3. 运行时边界

TypeScript 类型在构建后会被擦除。网络、表单、存储、环境变量、插件、消息和服务器响应仍是运行时不可信输入，必须按 JS 数据访问与安全规则校验。

## 4. 维护要求

- 🔴 不能把某个 `tsconfig`、ESLint 版本、插件或类型库设成所有项目的前提。
- 🔴 声明、类型断言和 lint 配置变更必须与实际构建、运行时或调用方验证配套。
- 🟡 修改专题后，更新本表并检查链接。
