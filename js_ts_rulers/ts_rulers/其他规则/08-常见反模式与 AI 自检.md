# 08 - TypeScript 常见反模式与 AI 自检

> 🟢 本文件适用于 TypeScript 常见反模式清单与 AI 自检要点。

> 🔴 不适用：业务逻辑实现

---

## 1. 🔴 反模式 · 绝对不要写

### 1.1 any 滥用

```ts
// ❌
function f(x: any) { return x.foo; }
const data: any = JSON.parse(input);
const handler: any = (e: Event) => {};

// ✅ unknown + 收窄 / zod 校验
function f(x: unknown) {
  if (typeof x === 'object' && x !== null && 'foo' in x) {
    return (x as { foo: string }).foo;
  }
}
```

**ESLint**：`@typescript-eslint/no-explicit-any: error`（已强制）

### 1.2 `as` 逃避类型检查

```ts
// ❌ 双断言
const value = unknownValue as unknown as User;

// ❌ JSON.parse + as 跳过校验
const user = JSON.parse(input) as User;

// ✅ zod 校验（首选）
const user = UserSchema.parse(JSON.parse(input));
```

**ESLint**：`@typescript-eslint/no-unsafe-*` 全套 error 级

### 1.3 `!` 非空断言

```ts
// ❌
const user = users.find(u => u.id === id)!;          // 不存在就崩

// ✅
const user = users.find(u => u.id === id);
if (!user) throw new Error('Not found');
```

**ESLint**：`@typescript-eslint/no-non-null-assertion: error`

### 1.4 装饰器用 legacy 版

```ts
// ❌ legacy 装饰器（已废弃）
@Component({ selector: 'app' })
class AppComponent {}

// ✅ TC39 Stage 3 装饰器
@logged
add(a: number, b: number) { return a + b; }
```

**tsconfig**：`experimentalDecorators: false`（用 TC39 新版）

### 1.5 函数反模式

```ts
// ❌ 默认导出整个对象
export default { getUser, createUser, deleteUser };

// ❌ 一个文件多个类
// user.ts 里塞：UserService + UserController + UserValidator

// ❌ 函数 > 50 行 / 参数 > 3 个不用 options 参数
function process(user, action, params, options, callback) { /* ... */ }

// ✅ 具名导出 + 拆函数 + options 参数
export function getUser() {}
export function createUser() {}

function process(options: { user: User; action: string }) { /* ... */ }
```

### 1.6 模块反模式

```ts
// ❌ barrel exports 滥用（自动补全变慢 / 循环依赖）
// index.ts
export * from './user';
export * from './order';
export * from './product';

// ❌ 循环依赖
// a.ts -> b.ts -> a.ts

// ❌ 全局副作用
window.myApp = { init() {} };

// ✅ 直接从文件导入 + 模块内单方向依赖
import { getUser } from './user/user.api';
```

### 1.7 类型反模式

```ts
// ❌ 占位 type
type T = any;                                       // 假装有类型

// ❌ 业务代码用条件类型 / 映射类型
type GetFieldType<T, K extends keyof T> = T[K] extends infer R ? R : never;

// ❌ type / interface 混用不知道选谁
type User = { id: number; name: string };            // 应该用 interface
interface Status = 'pending' | 'done';               // ❌ 语法错误（interface 不能 union）

// ✅ interface 给对象，type 给 union / 工具类型
interface User { id: number; name: string; }
type Status = 'pending' | 'done';
```

### 1.8 import 反模式

```ts
// ❌ 全部用 import（运行时仍加载类型 import）
import { User, getUser } from './user';

// ❌ import * 整个命名空间
import * as fs from 'fs';

// ❌ require 混入 ESM
const express = require('express');

// ✅ 类型 import 用 import type
import type { User } from './user';
import { getUser } from './user';
import fs from 'node:fs';
```

## 2. 🟡 团队约定补充

### 2.1 命名补充

```ts
// ✅ type / interface PascalCase
interface User { id: number }
type Status = 'pending' | 'done';

// ✅ 工具类型以 T 结尾（自定义工具时）
type PartialUser<T> = Partial<T>;

// ❌ 命名带 I 前缀（C# 风格）
interface IUser {}                                  // 不要
```

### 2.2 注释补充

```ts
/**
 * 计算折扣
 * @deprecated 用 getDiscountV2 替代
 * @see getDiscountV2
 */
function getDiscount(user: User) { /* ... */ }

/**
 * @throws {ValidationError} 当输入不合法
 * @example
 * const u = createUser({ name: 'alice' });
 */
export function createUser(input: UserInput): User { /* ... */ }
```

### 2.3 公共 API 模式

```ts
// ✅ 显式参数 + 返回类型 + JSDoc + named export
/**
 * 获取用户
 * @param id 用户 ID
 * @returns 用户对象（不存在返回 null）
 */
export function getUser(id: number): Promise<User | null> {
  return fetch(`/api/users/${id}`).then(r => r.json());
}
```

### 2.4 内部 / 外部 API 分层

```ts
// ❌ 所有东西都 export
export function internalHelper() {}                  // 应内部用

// ✅ 明确公开 / 内部
// src/api/user.ts - 外部 API（export）
// src/internal/user-helper.ts - 内部 helper（不 export）
```

## 3. 🟢 可选 · 自检工具

### 3.1 ts-unused-exports

```bash
npm install --save-dev ts-unused-exports
```

检测未使用的 export——定期清理。

### 3.2 dependency-cruiser

```bash
npm install --save-dev dependency-cruiser
```

依赖图 / 循环依赖检测。

```js
// .dependency-cruiser.cjs
module.exports = {
  forbidden: [
    {
      name: 'no-circular',
      severity: 'error',
      comment: '禁止循环依赖',
      from: {},
      to: { circular: true },
    },
  ],
};
```

```bash
npx depcruise src
```

### 3.3 type-coverage

```bash
npm install --save-dev type-coverage
```

```bash
npx type-coverage --at-least 95     # 至少 95% 类型覆盖
```

CI 卡口：类型覆盖率 < 95% 失败。

### 3.4 knip（未使用代码检测）

```bash
npm install --save-dev knip
```

检测未使用的 export / 文件 / 依赖。
