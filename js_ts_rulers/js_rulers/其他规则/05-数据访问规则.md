# 05 - JavaScript 数据访问规则

> 🟢 本文件适用于数据库访问层设计（SQL/索引/MyBatis/JPA/分库分表）。

> 🔴 不适用：NoSQL、消息队列、对象存储、缓存设计

---

## 1. 🔴 硬约束 · 这些绝对不要写

### 1.1 敏感数据放错位置

**JWT / token / 密码绝不存 `localStorage`**（XSS 可直接读取）。

```js
// ❌ XSS 一打即中
localStorage.setItem('token', jwtToken);

// ✅ 优先 Cookie（HttpOnly + Secure + SameSite）
// 后端响应时 Set-Cookie，前端自动带上

// 或 sessionStorage（仅会话级，XSS 仍可读）
```

**Cookie 三件套**（后端必加，前端了解）：

```
Set-Cookie: sessionId=xxx; HttpOnly; Secure; SameSite=Lax; Path=/
```

| 属性 | 作用 |
|------|------|
| `HttpOnly` | JS 不能读，防 XSS |
| `Secure` | 仅 HTTPS 传输 |
| `SameSite=Lax/Strict` | 防 CSRF |

**客户端不做权限决策**——前端只是 UI 隐藏，权限校验永远在后端。

### 1.2 localStorage 容量与同步阻塞

- 单条 ≤ 5MB，单域 ≤ 10MB
- 同步 API 阻塞主线程，**大量数据用 IndexedDB**

```js
// ❌ 大量数据写 localStorage 会卡
localStorage.setItem('bigData', JSON.stringify(hugeArray));

// ✅ 大量数据用 IndexedDB（异步，不阻塞）
const request = indexedDB.open('myDB', 1);
```

### 1.3 fetch 默认不带 cookie

```js
// ❌ 跨域不带 cookie
await fetch('https://api.example.com/user', {
  credentials: 'omit',                // 默认
});

// ✅ 需要 cookie 显式声明
await fetch('https://api.example.com/user', {
  credentials: 'include',
});
```

**跨域 cookie 需后端设置 `SameSite=None; Secure`**。

### 1.4 用户输入直接插入 DOM

```js
// ❌ XSS 风险
element.innerHTML = userInput;
element.outerHTML = userInput;

// ✅ 文本用 textContent
element.textContent = userInput;

// ✅ 富文本用 DOMPurify 净化
import DOMPurify from 'dompurify';
element.innerHTML = DOMPurify.sanitize(userInput);
```

### 1.5 没有超时与取消

见 [04 §推荐 1-2](./04-异步与事件循环.md) ——所有 fetch 必带超时 + AbortSignal。

### 1.6 缓存策略混乱

**显式声明缓存**：

```js
// ❌ 浏览器默认缓存，可能拿到旧数据
fetch('/api/user');

// ✅ 服务端返回 ETag / Cache-Control，前端用 If-None-Match
fetch('/api/user', {
  headers: { 'If-None-Match': etag },
});
// 服务端 304 Not Modified 表示仍可用
```

详见 [03 §6](./03-性能优化规则.md)。

## 2. 🟡 推荐 · 团队约定

### 2.1 存储选型表

| 场景 | 方案 | 备注 |
|------|------|------|
| 简单 key-value，单条 < 100KB | `localStorage` | 同步 API，**不要存大量数据** |
| 会话级 | `sessionStorage` | 标签页关闭即清 |
| 大量结构化数据 | `IndexedDB`（`idb` / `dexie` 封装） | 异步，不阻塞 |
| 服务端可读 | Cookie | 必加 HttpOnly + Secure + SameSite |
| 网络请求缓存 | Cache API / Service Worker | 离线 / 复杂缓存策略 |
| React 服务端态 | React Query / SWR / TanStack Query | 自带去重 / 缓存 / 失效 |

### 2.2 fetch 封装（项目级 wrapper）

```js
// ✅ 统一处理错误 / 超时 / 重试
class HttpClient {
  async request(url, options = {}) {
    const controller = new AbortController();
    const timeout = options.timeout ?? 5000;
    const timer = setTimeout(() => controller.abort(), timeout);

    try {
      const res = await fetch(url, {
        ...options,
        signal: controller.signal,
      });
      if (!res.ok) throw new HttpError(res.status, await res.text());
      return res.json();
    } finally {
      clearTimeout(timer);
    }
  }

  get(url, params) { return this.request(`${url}?${new URLSearchParams(params)}`); }
  post(url, data) { return this.request(url, { method: 'POST', body: JSON.stringify(data) }); }
}
```

### 2.3 跨标签页通信

| 方案 | 适用 |
|------|------|
| `BroadcastChannel` | 同源 tab 间，API 简单 |
| `SharedWorker` | 复杂状态共享 |
| `localStorage` + `storage` 事件 | 兼容老浏览器 |
| `postMessage` + iframe | 跨域父 ↔ 子 |

```js
// ✅ BroadcastChannel
const channel = new BroadcastChannel('user-sync');
channel.postMessage({ type: 'logout' });
channel.onmessage = (e) => {
  if (e.data.type === 'logout') handleLogout();
};
```

### 2.4 IndexedDB 封装（dexie / idb）

```js
import Dexie from 'dexie';
const db = new Dexie('myDB');
db.version(1).stores({
  users: '++id, name, createdAt',     // ++id 自增主键，索引字段
});

await db.users.add({ name: 'alice', createdAt: Date.now() });
const all = await db.users.toArray();
```

### 2.5 数据校验（zod / yup）

**外部数据进应用前必校验**（API 响应 / localStorage / URL 参数）。

```js
import { z } from 'zod';

const UserSchema = z.object({
  id: z.number().int().positive(),
  name: z.string().min(1).max(50),
  email: z.string().email(),
});

const raw = await fetch('/api/user/1').then(r => r.json());
const user = UserSchema.parse(raw);    // 校验失败抛错
```

TS 项目见 [ts_rulers/02-类型守卫与收窄](../../ts_rulers/其他规则/02-类型守卫与收窄.md)。
