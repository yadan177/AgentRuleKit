# 11 - JavaScript 安全规则（🟠 强制）

> 🟢 本文件适用于 Java 项目安全红线（OWASP Top 10/BCrypt/JWT/Spring Security）。

> 🔴 不适用：业务逻辑实现、UI 样式设计

---

## 1. 🟠 强制 · 安全红线

### 1.1 XSS（跨站脚本）

**用户输入必须转义或净化**。

```js
// ❌ XSS 风险
element.innerHTML = userInput;
element.outerHTML = userInput;
document.write(userInput);

// ✅ 文本用 textContent
element.textContent = userInput;

// ✅ 富文本用 DOMPurify 净化
import DOMPurify from 'dompurify';
element.innerHTML = DOMPurify.sanitize(userInput);

// ✅ React 用 dangerouslySetInnerHTML 时也必须净化
<div dangerouslySetInnerHTML={{ __html: DOMPurify.sanitize(html) }} />
```

**URL 校验**（防 `javascript:` 协议）：

```js
function safeUrl(url) {
  try {
    const parsed = new URL(url);
    return ['http:', 'https:', 'mailto:'].includes(parsed.protocol);
  } catch {
    return false;
  }
}
```

**Content-Security-Policy**（防 XSS 即使被注入）：

```http
Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self' https://api.example.com
```

### 1.2 CSRF（跨站请求伪造）

**POST 必须带 CSRF token**。

```js
// ✅ 从 cookie 读 CSRF token
const csrfToken = document.cookie.match(/csrf=([^;]+)/)?.[1];

await fetch('/api/transfer', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-CSRF-Token': csrfToken,
  },
  credentials: 'include',
  body: JSON.stringify(data),
});
```

**SameSite Cookie**：

```
Set-Cookie: sessionId=xxx; HttpOnly; Secure; SameSite=Lax; Path=/
```

**Origin / Referer 校验**（后端）。

### 1.3 SQL / NoSQL 注入

```js
// ❌ 字符串拼接（SQL 注入）
const query = `SELECT * FROM users WHERE name = '${userName}'`;

// ✅ 参数化查询
const query = 'SELECT * FROM users WHERE name = ?';
db.query(query, [userName]);

// ❌ NoSQL 注入（MongoDB）
db.users.find({ name: req.body.name });           // 传 { $gt: '' } 全表扫

// ✅ 类型校验 + 白名单
const name = String(req.body.name);
if (!/^[a-zA-Z0-9]+$/.test(name)) throw new Error('Invalid name');
db.users.find({ name });
```

**所有用户输入都要校验**：使用项目已有的校验方案（例如 zod / yup / joi / class-validator）；TS 见 [ts_rulers/02](../../ts_rulers/其他规则/02-类型守卫与收窄.md)。不要仅为本节示例新增校验依赖。

### 1.4 认证与授权

**token 不放 localStorage**（XSS 可读）：

```js
// ❌
localStorage.setItem('token', jwtToken);

// ✅ Cookie（HttpOnly + Secure + SameSite=Strict）
// 后端 Set-Cookie，前端自动带上
```

**短 token + 刷新机制**：

- access token：15 分钟
- refresh token：7 天，存 HttpOnly Cookie 或服务端 session
- refresh token 一次使用作废（防重放）

**客户端不做权限决策**：

```js
// ❌ 前端判断权限，后端不校验
if (user.role === 'admin') {
  showAdminButton();           // 隐藏只是 UI，真正的权限在后端
}

// ✅ 后端必须校验权限
await fetch('/api/admin/users', { credentials: 'include' });   // 后端返回 403 就 403
```

### 1.5 密码与加密

**前端哈希密码** = ❌（密钥暴露，浪费时间）。

```js
// ❌ 前端 SHA256
const hashedPassword = sha256(password);

// ✅ 密码直接 POST 到后端，后端用 bcrypt / argon2 哈希
await fetch('/api/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email, password }),      // HTTPS 加密传输
});
```

**HTTPS 全站**——HTTP 凭证会明文传输。

**客户端不存私钥 / 不做加密逻辑**——密钥会暴露。

### 1.6 依赖安全

```bash
# 定期审计
npm audit
npm audit fix

# 锁定版本（package-lock.json 入库）
npm ci    # 不用 npm install（严格按 lock）
```

**不引未知小库**——下载量 < 1000 / 无 GitHub 仓库 / 作者匿名的库 = 风险。

**Snyk / Dependabot** 自动检测已知漏洞。

### 1.7 敏感数据保护

**不打日志**：

```js
// ❌
console.log('Login attempt:', { email, password });
logger.info('User:', { id, password, ssn });

// ✅ 过滤敏感字段
logger.info('User:', { id, name });
```

**脱敏展示**：

```js
function maskPhone(phone) {
  return phone.replace(/(\d{3})\d{4}(\d{4})/, '$1****$2');
}
maskPhone('13800138000');     // => '138****8000'
```

**不要在客户端做权限决策**——同上 §4。

## 2. 🟡 推荐 · 加固措施

### 2.1 CSP（Content-Security-Policy）

```html
<meta http-equiv="Content-Security-Policy"
      content="default-src 'self';
               script-src 'self';
               style-src 'self' 'unsafe-inline';
               img-src 'self' data: https:;
               connect-src 'self' https://api.example.com">
```

**严格模式**：
- 禁 inline script（用 nonce）
- 禁 eval
- 限制 script 源

### 2.2 Subresource Integrity（SRI）

```html
<script src="https://cdn.example.com/lib.js"
        integrity="sha384-abc123..."
        crossorigin="anonymous"></script>
```

第三方 CDN 资源哈希校验，篡改即拒绝执行。

### 2.3 安全响应头

```http
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
Strict-Transport-Security: max-age=31536000; includeSubDomains
Referrer-Policy: no-referrer
Permissions-Policy: geolocation=(), microphone=(), camera=()
```

### 2.4 输入校验（白名单）

```js
import { z } from 'zod';

const SignupSchema = z.object({
  email: z.string().email().max(100),
  password: z.string().min(8).max(128),
  age: z.number().int().min(13).max(150),
});

const result = SignupSchema.safeParse(input);
if (!result.success) {
  return res.status(400).json({ errors: result.error.issues });
}
```

**白名单 > 黑名单**——只允许已知安全值，禁止未知的。

### 2.5 速率限制（前端）

```js
// 简单的按钮防抖 / 节流
function throttle(fn, delay = 1000) {
  let last = 0;
  return (...args) => {
    const now = Date.now();
    if (now - last >= delay) {
      last = now;
      fn(...args);
    }
  };
}

button.addEventListener('click', throttle(handleClick, 1000));
```

## 3. 🟢 可选 · 高级主题

### 3.1 OAuth 2.0 / OpenID Connect

第三方登录（GitHub / Google / Apple）：

- 用官方 SDK（`@auth/core` / `next-auth`）
- 不要自己实现 OAuth 流程

### 3.2 WebAuthn（生物识别 / 硬件密钥）

替代密码：

```js
const credential = await navigator.credentials.create({
  publicKey: {
    challenge: new Uint8Array(32),
    rp: { name: 'Example Corp' },
    user: {
      id: new Uint8Array(16),
      name: 'alice@example.com',
      displayName: 'Alice',
    },
    pubKeyCredParams: [{ alg: -7, type: 'public-key' }],
  },
});
```

### 3.3 CSP nonce 模式

```js
// 服务端生成 nonce
const nonce = crypto.randomBytes(16).toString('base64');

// 模板
<script nonce="<%= nonce %>">...</script>

// CSP 头
Content-Security-Policy: script-src 'nonce-<%= nonce %>'
```
