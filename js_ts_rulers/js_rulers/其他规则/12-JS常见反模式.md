# 12 - JavaScript 专项反模式自检

> 🟢 本文件适用于 JavaScript 运行时特有问题的补充自检，应与 [JS/TS AI 交付前自检](../../02-AI交付前自检.md) 一起使用。
>
> 🔴 不适用：以反模式名义无授权重构存量代码、替换框架或批量修改无关模块。

---

## 1. JavaScript 运行时补充

- [ ] 没有依赖隐式全局、意外类型转换或未声明的可变共享状态。
- [ ] 没有吞掉异常、Promise rejection 或清理错误。
- [ ] 浏览器/Node 专有 API 仅在真实运行环境可用时调用，并考虑 SSR、测试和 worker 边界。
- [ ] DOM、URL、样式和脚本 sink 未接收不可信原始内容。

## 2. 使用边界

🔴 **必须**：反模式判断应以当前运行时、框架、调用方和可复现行为为准；不能把语言偏好或规则样例当作全仓重构依据。

🟡 **推荐**：需要进一步判断时，分别查阅 JS 01（运行时）、JS 03（性能）、JS 04（异步）、JS 05（数据）与 JS 11（安全）专题。
