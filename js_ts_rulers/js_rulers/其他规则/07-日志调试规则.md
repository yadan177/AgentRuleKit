# 07 - JavaScript 日志调试规则

> 🟢 本文件适用于 JavaScript 项目日志与调试（console/Sentry/Source Map）。

> 🔴 不适用：metrics 指标采集、tracing 链路追踪、APM 工具

---

## 1. 🔴 硬约束 · 这些绝对不要写

### 1.1 生产环境留 `console.log`

**生产构建时移除**：

- Vite：用 `terser` 的 `drop_console: true`
- Webpack：`TerserPlugin` 的 `drop_console: true`

```js
// vite.config.js
export default defineConfig({
  build: {
    minify: 'terser',
    terserOptions: {
      compress: {
        drop_console: true,                  // 移除 console.*
        drop_debugger: true,                  // 移除 debugger
      },
    },
  },
});
```

**关键日志走专业 logger**（不是 console）。

### 1.2 错误吞掉（catch 不上报）

```js
// ❌ 错误被吞了
try { parseData(input); } catch (e) {}

// ✅ 上报到监控平台
try { parseData(input); }
catch (e) {
  Sentry.captureException(e, { extra: { input } });
  throw e;
}
```

### 1.3 没有 Source Map（线上排错）

- 生产隐藏源码（构建 minify）
- **上传 Source Map 到监控平台**（Sentry / Bugsnag / 自建）

```js
// vite.config.js（生产环境隐藏 sourcemap URL）
build: {
  sourcemap: 'hidden',
}
```

**不要**在客户端暴露 Source Map URL（暴露了等于开源）。

## 2. 🟡 推荐 · 团队约定

### 2.1 console 5 级体系

| 级别 | 用途 | 生产处理 |
|------|------|---------|
| `console.error` | 致命错误 | 上报 + 保留 |
| `console.warn` | 警告 | 保留（可采样上报） |
| `console.info` | 业务信息 | 移除 |
| `console.debug` | 调试 | 移除 |
| `console.trace` | 堆栈 | 移除 |

### 2.2 结构化日志（业务上下文）

```js
// ❌ 字符串拼贴，监控平台难以解析
console.log('User', userId, 'failed to login');

// ✅ 结构化对象
logger.error({
  event: 'login_failed',
  userId,
  reason: e.message,
  ip: request.ip,
  traceId,
});
```

**必要字段**：`traceId`（一次请求贯穿）/ `userId` / `businessTag`。

### 2.3 错误上报（Sentry / Bugsnag / 自建）

```js
import * as Sentry from '@sentry/browser';

Sentry.init({
  dsn: 'https://xxx@sentry.io/xxx',
  environment: process.env.NODE_ENV,
  tracesSampleRate: 0.1,                   // 10% 性能采样
  beforeSend(event) {                       // 过滤敏感字段
    if (event.user) delete event.user.password;
    return event;
  },
});
```

**上报前过滤敏感数据**（密码 / token / 身份证 / 手机号）。

### 2.4 debugger 移除（提交前检查）

**ESLint 规则**：

```json
{ "rules": { "no-debugger": "error" } }
```

**Pre-commit hook**：

```json
// package.json
{
  "lint-staged": {
    "*.{js,ts}": ["eslint --fix"]
  }
}
```

### 2.5 调试技巧

- **条件断点**：断点上右键设条件
- **blackbox 第三方代码**：Sources > 右键 > Blackbox
- **Performance 录制**：录制一段时间看 timeline
- **Network 面板**：看瀑布图、请求头、响应体
- **React DevTools Profiler**：看组件渲染时长
- **Vue DevTools**：组件树 / Pinia 状态 / 路由

## 3. 🟢 可选 · 视情况

### 3.1 性能日志（PerformanceObserver）

```js
const observer = new PerformanceObserver((list) => {
  for (const entry of list.getEntries()) {
    logger.info({ event: 'web_vital', name: entry.name, value: entry.value });
  }
});
observer.observe({ type: 'largest-contentful-paint', buffered: true });
observer.observe({ type: 'layout-shift', buffered: true });
```

### 3.2 业务埋点（analytics）

与错误日志**分离**：

```js
analytics.track('button_clicked', { buttonId: 'submit' });
```

**不要**用错误上报系统做业务埋点（污染错误率指标）。
