## 1. 使用方式

先遵守 [01 - JS/TS AI 通用入口规则](../01-AI通用入口规则.md)，再按任务读取本目录专题；交付前使用 [JS/TS AI 交付前自检](../02-AI交付前自检.md)。TypeScript 项目还应按需读取 [TS 专题总览](../ts_rulers/00-文档总览.md)。

🔴 **必须**：项目已有框架、运行时、模块格式、请求层、样式、测试和构建配置优先于本目录示例。

## 3. 与 TypeScript 的边界

JavaScript 基线负责运行时行为、异步、安全、测试和工程协作。`type`、类型收窄、声明文件、tsconfig 和 TS lint 等仅由 `../ts_rulers/` 规则补充。

🟡 **推荐**：TS 项目先把本目录用于运行时和工程规则，再按任务加载 TS 专题；不因使用 TS 而忽略浏览器/Node 运行时验证。

## 4. 维护要求

- 🔴 规则示例不是项目事实，不能据此新增包、命令、框架或配置。
- 🔴 涉及版本、依赖、工具、框架或部署时，必须写明适用条件、验证与例外。
- 🟡 修改专题后，更新本表并检查链接。
