# 00 - JS/TS AI 项目入口规则

> 🟢 本入口适用于 Qoder 在接入本规则库的 JavaScript 或 TypeScript 项目中执行开发、审查和排障任务。
>
> 🔴 不适用：替代 `.ai-rules/js-ts/` 中的完整规则或覆盖目标项目中更具体的规则。

---

## 1. 使用要求

将本规则在 Qoder 中设为“始终生效”。执行 JS/TS 任务前，先读取 `.ai-rules/js-ts/01-AI通用入口规则.md`，再按 `.ai-rules/js-ts/00-文档总览.md` 选择专题规则。

## 2. 执行约束

- 🔴 必须检查 `package.json`、锁文件、scripts、运行时/包管理器、tsconfig、依赖、同目录实现、测试、构建和部署配置。
- 🔴 只使用项目已验证可用的包、API 与命令；不确定时采用已有实现或询问用户。
- ❌ 禁止臆造依赖、接口、环境变量、DOM、命令、测试结果或项目架构。
- ❌ 禁止未授权升级运行时/依赖、迁移框架/构建/状态/样式体系或进行无关重构。
