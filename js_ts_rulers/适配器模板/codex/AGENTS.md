# 00 - JS / TS Codex 项目入口规则

---

执行 JavaScript 或 TypeScript 任务前，先阅读 `.ai-rules/js/15-AI通用入口规则.md`，再按 `.ai-rules/js/00-文档总览.md` 读取当前任务相关专题规则。

如项目包含 `tsconfig*.json`、`.ts`/`.tsx` 源码或 TypeScript 构建脚本，额外阅读 `.ai-rules/ts/09-AI通用入口规则.md` 与 `.ai-rules/ts/00-文档总览.md`。

- 🔴 必须检查 `package.json`、锁文件、运行时/框架版本、构建脚本、配置与同模块既有实现。
- 🔴 必须只使用项目已验证可用的 API 与依赖；不确定时复用现有实现或询问用户。
- ❌ 禁止臆造依赖、命令、测试结果、接口或项目架构；禁止未经授权升级运行时/框架/工具链或进行无关重构。
- 🔴 执行与改动相称的现有验证；无法执行时说明原因、未验证范围与风险。
