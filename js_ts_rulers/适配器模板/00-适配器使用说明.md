# 00 - JS/TS AI 规则适配器使用说明

> 🟢 本文件说明如何把 JavaScript 与 TypeScript 规则库接入 Codex、Cursor、Qoder、TRAE 或其他 AI 工具。
>
> 🔴 不适用：将完整规则复制到多个工具配置中；完整规则只维护一份。

---

## 1. 目标与原则

本目录提供的是**薄入口模板**，不是四份完整规则副本。

- 🔴 先将 `js_ts_rulers/` 复制到目标项目的 `.ai-rules/js-ts/`，保留 `js_rulers/` 与 `ts_rulers/` 层级。
- 🔴 只复制当前实际使用的 AI 工具对应模板到目标项目根目录。
- 🟡 推荐将 `.ai-rules/js-ts/` 与选用的规则配置一并纳入项目版本控制。

## 2. 目标项目目录

```text
<project>/
├── .ai-rules/
│   └── js-ts/
│       ├── 00-文档总览.md
│       ├── 01-AI通用入口规则.md
│       ├── js_rulers/
│       └── ts_rulers/
├── AGENTS.md                       # 仅 Codex 模板需要
├── .cursor/rules/js-ts-core.mdc    # 仅 Cursor 模板需要
└── .qoder/rules/js-ts-core.md      # 仅 Qoder 模板需要
```

## 3. 安装方式

### 3.1 Codex

将 `codex/AGENTS.md` 复制到目标项目根目录；入口只定位通用规则，再按任务定位 JS 或 TS 专题。

### 3.2 Cursor

将 `cursor/.cursor/` 复制到目标项目根目录。`js-ts-core.mdc` 仅包含 Cursor frontmatter 和短入口指令，不复制完整规则内容。

### 3.3 Qoder

将 `qoder/.qoder/` 复制到目标项目根目录。在 Qoder 的“规则”设置中将 `js-ts-core` 设为“始终生效”。

### 3.4 TRAE 与其他 AI 工具

参见 `trae/00-TRAE手动使用说明.md`。在未确认工具的项目规则格式前，手动附加 01 号规则和当前任务需要的 JS/TS 专题规则。

## 4. 维护要求

- 🔴 `.ai-rules/js-ts/` 是唯一完整规则来源。
- 🔴 修改 01 号规则后，检查三个自动入口是否仍能定位到它。
- ❌ 不得在适配器中复制整套专题规则，避免多份内容漂移。
