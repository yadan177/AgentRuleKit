# 00 - JS / TS AI 规则适配器使用说明

---

## 1. 目标与原则

本目录提供将 JS/TS 规则库接入 Codex、Qoder 与 TRAE 的**薄入口**。完整规则只维护在 `js_rulers/` 和 `ts_rulers/` 中；适配器先路由 JS 基线，再在 TypeScript 项目追加 TS 专题。

- 🔴 **必须**保留两个目录的现有专题文档；适配器不得复制整套正文。
- 🔴 TypeScript 项目必须先加载 JS 基线入口，再加载 TS 入口。
- 🟡 推荐将规则库与实际使用的入口配置一并纳入版本控制。

## 2. 目标项目结构

```text
<js-or-ts-project>/
├── .ai-rules/
│   ├── js/                       # 完整复制 js_rulers/
│   └── ts/                       # TS 项目完整复制 ts_rulers/
├── AGENTS.md                     # Codex 入口
└── .qoder/rules/js-ts-core.md    # Qoder 入口
```

## 3. 安装方式

### 3.1 Codex

将 JS 规则复制到 `.ai-rules/js/`；TypeScript 项目同时将 TS 规则复制到 `.ai-rules/ts/`。再将 `codex/AGENTS.md` 复制到项目根目录。

### 3.2 Qoder

按上述结构复制规则库，再将 `qoder/.qoder/` 复制到项目根目录，并在 Qoder 中将 `js-ts-core` 设为始终生效。

### 3.3 TRAE

未核实当前 TRAE 版本的稳定项目规则存储格式前，按 [TRAE 手动使用 JS / TS AI 规则说明](./trae/00-TRAE手动使用说明.md) 手动附加入口，不猜测配置路径。

## 4. 维护要求

- 🔴 修改 JS 15 或 TS 09 入口后，必须检查三个适配器仍能定位到它们。
- 🔴 移动或改名专题文档后，必须更新总览与适配器链接。
- ❌ 禁止在多个适配器中复制完整专题规则，造成多份内容漂移。
