# 00 - TRAE 手动使用 JS / TS AI 规则说明

---

## 1. 使用方式

未核实当前 TRAE 版本的项目规则格式前，请按任务手动附加：

1. `.ai-rules/js/15-AI通用入口规则.md`；
2. `.ai-rules/js/00-文档总览.md`；
3. 当前任务直接相关的 JS 专题规则；
4. 若为 TypeScript 项目，再附加 `.ai-rules/ts/09-AI通用入口规则.md`、TS 总览与相关 TS 专题。

## 2. 推荐提示词

```text
先遵守已附加的 JS/TS AI 通用入口规则；检查 package.json、锁文件、运行时、构建脚本、配置和同模块实现后，再完成当前任务。不要升级运行时、框架、工具链或新增依赖，除非我明确授权。最后报告修改、验证、未验证项与风险。
```

## 3. 后续适配

当 TRAE 官方资料明确稳定的项目规则路径和触发方式后，再增加自动加载模板；在此之前不要猜测或创建未验证的配置文件。
