# 00 - TRAE 手动使用 JS/TS AI 规则说明

> 🟢 本说明适用于需要在 TRAE 中手动附加 JavaScript 与 TypeScript 规则的项目。
>
> 🔴 不适用：假定未确认的 TRAE 自动规则目录或配置格式。

---

## 1. 使用方式

本规则库首期不假设 TRAE 的自动规则文件格式。请在当前 TRAE 版本中手动附加：

1. `.ai-rules/js-ts/01-AI通用入口规则.md`。
2. `.ai-rules/js-ts/00-文档总览.md`。
3. 当前任务需要的 JS 基线规则，以及（若为 TS 项目）所需 TS 专题规则。

## 2. 推荐提示词

```text
先遵守已附加的 JS/TS AI 通用入口规则；检查 package.json、锁文件、scripts、运行时/包管理器、tsconfig、依赖、同目录既有实现和可用验证命令后，再完成当前任务。不要升级运行时、依赖、框架、构建、状态、样式或基础设施，除非我明确授权。最后报告修改、验证、未验证项与风险。
```

## 3. 后续适配

- 🟡 当 TRAE 官方文档明确项目规则的稳定存储路径和触发方式后，再增加自动加载模板。
- ❌ 在此之前，不猜测或创建未验证的 TRAE 配置文件。
