# 平台无关工作流

工作流定义以平台无关方式描述任务意图、输入输出和安全边界。它是未来独立 Skill 库的候选来源；场景能力插件可组合多个 Skills 与工具，并将前一阶段产物交给后一阶段。项目按需选择产品规划、UI、前端、后端、Unity 等插件，不强制执行一条固定的开发流水线。Skill 在执行时应读取当前企业与项目生效的规则，不在通用流程或插件中复制规则正文。IDE 适配器可以将流程转换为原生 Skills、命令、提示模板或其他受支持形式。

旧的四个 Codex 规则管理 Skill 与插件包已经退役。安装、更新和卸载由工具箱桌面端或 CLI 执行；代码审查和文档影响判断目前没有自动工作流。本目录暂不包含可执行的跨平台 Skill 定义；首个真实开发任务试点确定输入、输出和依赖后再新增资产。产品资产边界见[产品定位与架构](../docs/product-architecture.md)。
