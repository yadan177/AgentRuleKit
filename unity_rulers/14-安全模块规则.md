# 14 - Unity 安全模块规则

> 🟢 本文件适用于 Unity 项目的安全防护（客户端数据 / 反作弊 / 资源保护 / 网络安全 / 用户隐私 / 支付安全）。

> 🔴 不适用：纯单机游戏（无网络）、纯服务端业务逻辑（用对应语言规则）、UI 样式设计

---

## 1. 客户端数据安全

### 1.1 存储选型

| 平台 | 推荐方案 | 加密 |
|---|---|---|
| **iOS** | Keychain | 系统级加密 |
| **Android** | EncryptedSharedPreferences / Keystore | AES-256 |
| **Windows** | DPAPI / Credential Manager | 系统级 |
| **Editor（仅调试）** | EditorPrefs | **不加密**（仅本地开发） |

🟡 推荐：**用跨平台抽象层**（如 `ISecureStorage` 接口）。

```csharp
public interface ISecureStorage {
    void Save(string key, string value);
    string Load(string key);
    void Delete(string key);
}

// iOS 实现：Security.framework / Keychain
// Android 实现：EncryptedSharedPreferences
// Windows 实现：DPAPI
```

🔴 必加约束：

- ✅ **Token / API Key 用安全存储**（不用 PlayerPrefs）
- ✅ **不要存明文密码**
- ✅ **不存游戏存档以外的敏感数据**

### 1.2 存档加密

🟡 推荐：本地游戏存档用 AES 加密。

```csharp
public static class SaveSerializer {
    private static readonly byte[] Key = LoadKeyFromSecureStorage();

    public static void Save<T>(T data) where T : class {
        var json = JsonSerializer.Serialize(data);
        var plain = Encoding.UTF8.GetBytes(json);
        var encrypted = AesEncrypt(plain, Key);
        File.WriteAllBytes(GetSavePath(), encrypted);
    }

    public static T Load<T>() where T : class {
        var encrypted = File.ReadAllBytes(GetSavePath());
        var plain = AesDecrypt(encrypted, Key);
        var json = Encoding.UTF8.GetString(plain);
        return JsonSerializer.Deserialize<T>(json);
    }

    private static byte[] AesEncrypt(byte[] plain, byte[] key) {
        using var aes = Aes.Create();
        aes.Key = key;
        aes.GenerateIV();
        // ... 加密逻辑
    }
}
```

## 2. 反作弊（服务端权威）

### 2.1 设计原则

🔴 必加约束：**所有关键判定放服务端**——不信任客户端数据。

| 操作 | 客户端角色 | 服务端角色 |
|---|---|---|
| **伤害计算** | 提交攻击请求 | 计算伤害、扣 HP |
| **奖励发放** | 提交成就 | 验证成就、发放奖励 |
| **排行榜** | 提交分数 | 服务端计分（不信任客户端分数）|
| **抽卡 / 开箱** | 请求开箱 | 服务端随机 + 发放 |
| **支付** | 请求支付 | 服务端验证 + 发放 |

```csharp
// ❌ 危险：客户端算伤害
float damage = attack * 1.5f - defense * 0.3f;
enemyHealth -= damage;  // 作弊：damage 可被修改为 99999

// ✅ 正确：客户端提交，服务端算
public async Task AttackAsync(int targetId, int skillId) {
    await _api.PostAsync("/v1/battle/attack", new {
        targetId, skillId
        // 不带 damage —— 服务端算
    });
}
```

### 2.2 服务端检测

🟡 推荐：服务端检测异常行为。

| 检测项 | 异常 |
|---|---|
| 攻击频率 | 1 秒内攻击 > 10 次 |
| 单次伤害 | 1 秒内造成伤害 > 100000 |
| 通关速度 | 30 秒内通关正常需 10 分钟的关卡 |
| 金币变化 | 单次获得金币 > 1000000 |
| 设备异常 | 模拟器 / Root / 调试器 |

```csharp
// 服务端伪代码
public async Task<BattleResult> ProcessAttackAsync(long playerId, AttackRequest req) {
    var lastAttack = await _redis.GetAsync($"last_attack:{playerId}");
    if (DateTime.UtcNow - lastAttack < TimeSpan.FromMilliseconds(100))
        throw new RateLimitException("操作过于频繁");

    var player = await _db.GetPlayerAsync(playerId);
    var skill = await _db.GetSkillAsync(req.SkillId);
    var damage = CalculateDamage(player, skill, req);

    if (damage > player.MaxPossibleDamage * 1.5)
        await _auditLog.LogAsync("SUSPICIOUS_DAMAGE", playerId, damage);

    await ApplyDamage(req.TargetId, damage);
    return new BattleResult { Damage = damage };
}
```

## 3. 客户端防作弊（基础防护）

> ⚠️ **重要**：客户端防作弊是**纵深防御**——不替代服务端验证。

### 3.1 检测 Root / 越狱

🟡 推荐：检测设备是否被 Root / 越狱（合规与防作弊需求）。

```csharp
public class DeviceIntegrity {
    public bool IsCompromised() {
#if UNITY_ANDROID && !UNITY_EDITOR
        return CheckRootBinaries() || CheckSuBinary() || CheckRWAccess();
#elif UNITY_IOS && !UNITY_EDITOR
        return CheckJailbreakFiles() || CheckCydiaURL() || CheckFork();
#else
        return false;  // Editor / 其他平台
#endif
    }
}
```

🔴 注意：**不要直接禁用游戏功能**——检测到 Root 只是上报，让用户选择继续玩或退出。

### 3.2 检测调试器

🟡 推荐：检测调试器（仅 Release 模式启用）。

```csharp
public class DebuggerDetector {
    public bool IsDebuggerAttached() {
#if !UNITY_EDITOR && (DEVELOPMENT_BUILD || UNITY_EDITOR)
        return false;
#elif UNITY_ANDROID
        return AndroidJavaClass
            .FromType("android.os.Debug")
            .CallStatic<bool>("isDebuggerConnected");
#elif UNITY_IOS
        return CheckDebuggerSysctl();
#else
        return false;
#endif
    }
}
```

🔴 必加约束：

- ✅ **仅在 Release 构建启用**（不影响开发体验）
- ✅ **上报不阻断**（调试器可能是合法用户）
- ✅ **避免误判**（LPSCHR / lldb-server / 模拟器都会触发）

### 3.3 内存修改检测

🟡 推荐：定期校验关键值（防止 Cheat Engine 修改）。

```csharp
// 客户端：定期验证 HP/金币是否与服务端一致
public IEnumerator ValidateStateLoop() {
    while (true) {
        yield return new WaitForSeconds(60f);
        var serverState = await _api.GetPlayerStateAsync();
        if (serverState.Hp != LocalPlayer.Hp) {
            Debug.LogWarning("HP 异常，重置");
            LocalPlayer.Hp = serverState.Hp;
        }
    }
}
```

## 4. 资源保护

### 4.1 Asset Bundle 加密

🟡 推荐：使用 Asset Bundle 加密防止资源被提取。

```csharp
// 加密 Asset Bundle
public class EncryptedBundleLoader {
    public byte[] Key = LoadKeyFromSecureStorage();

    public async Task<AssetBundle> LoadBundleAsync(string path) {
        var encrypted = File.ReadAllBytes(path);
        var decrypted = AesDecrypt(encrypted, Key);
        var request = AssetBundle.LoadFromMemoryAsync(decrypted);
        return await request;
    }
}
```

### 4.2 IL2CPP 与代码混淆

🟡 推荐：**Release 构建用 IL2CPP**（iOS 必须）+ 代码混淆。

| 平台 | 必加 | 推荐 |
|---|---|---|
| **iOS** | ✅ IL2CPP | 加固（iXGuard / HuoRong） |
| **Android** | ✅ IL2CPP | ProGuard / DexGuard |
| **Windows / Mac** | 视情况 | .NET Reactor |

🔴 必加约束：

- ✅ **Release 必须用 IL2CPP**（iOS 强制，Android 推荐）
- ✅ **不要把业务密钥硬编码**（即使混淆也能反编译）

### 4.3 防资源提取

🟡 推荐：使用 Addressables + 加密（详见 09-资源管理规则）。

## 5. 网络安全

### 5.1 必加约束

- ✅ **所有 API 用 HTTPS**（明文 HTTP = 用户数据裸奔）
- ✅ **请求签名**（防重放 + 防篡改）
- ✅ **Token 绑定设备**（防跨设备滥用）
- ✅ **关键操作服务端校验**（不信任客户端）

### 5.2 请求签名

```csharp
public class SignedRequest {
    public string Sign(string method, string path, string body, long timestamp) {
        var message = $"{method}\n{path}\n{body}\n{timestamp}";
        using var hmac = new HMACSHA256(_secret);
        var hash = hmac.ComputeHash(Encoding.UTF8.GetBytes(message));
        return Convert.ToBase64String(hash);
    }
}

public async Task<ApiResult<T>> SendSignedAsync<T>(string method, string path, object body) {
    var timestamp = DateTimeOffset.UtcNow.ToUnixTimeSeconds();
    var json = JsonSerializer.Serialize(body);
    var sign = Sign(method, path, json, timestamp);

    _client.DefaultRequestHeaders.Add("X-Sign", sign);
    _client.DefaultRequestHeaders.Add("X-Timestamp", timestamp.ToString());

    var response = await _client.SendAsync(new HttpRequestMessage(...) { Content = ... });
    // ...
}
```

服务端验证签名：
```csharp
// 服务端伪代码
public async Task<ApiResult> HandleRequestAsync(HttpRequest req) {
    var clientSign = req.Headers["X-Sign"];
    var clientTimestamp = long.Parse(req.Headers["X-Timestamp"]);
    var now = DateTimeOffset.UtcNow.ToUnixTimeSeconds();

    if (Math.Abs(now - clientTimestamp) > 300) // ±5 分钟
        return ApiResult.Fail("TIMESTAMP_EXPIRED");

    var message = $"{req.Method}\n{req.Path}\n{await req.ReadBodyAsync()}\n{clientTimestamp}";
    var expectedSign = ComputeHmacSha256(message, _secret);
    if (clientSign != expectedSign)
        return ApiResult.Fail("INVALID_SIGNATURE");

    // 通过校验
    return await ProcessRequestAsync(req);
}
```

### 5.3 反调试（网络层）

🟡 推荐：检测异常 IP 模式（同账号多 IP / 高频切换 IP）。

```csharp
// 服务端伪代码
var recentIps = await _redis.LRangeAsync($"user:{userId}:ips", 0, 9);
if (recentIps.Distinct().Count() > 5) {
    await _fraudDetector.FlagAsync(userId, "MULTIPLE_IPS");
    // 可能触发：强制二次验证 / 临时封号
```

## 6. 用户隐私

### 6.1 必加约束

- ✅ **遵守《个人信息保护法》（PIPL） / GDPR**
- ✅ **明确告知收集哪些数据**（隐私政策）
- ✅ **用户可导出 / 删除自己的数据**（数据可携权）
- ✅ **未成年人保护**（实名认证、防沉迷、未成年退款）

### 6.2 数据收集最小化

🔴 必加约束：**只收集业务需要的数据**。

| 数据 | 是否必要 | 用途 |
|---|---|---|
| 设备 ID | ✅ 必要 | 封号 / 行为分析 |
| 手机号 | ⚠️ 看场景 | 实名 / 客服 |
| 身份证 | ⚠️ 看场景 | 实名 / 防沉迷 |
| 地理位置 | ❌ 通常不必要 | — |
| 通讯录 | ❌ 严禁 | — |
| 短信 | ❌ 严禁 | — |

### 6.3 数据加密与脱敏

详见 14.5 网络安全。

## 7. 支付安全

### 7.1 服务端验证（必加）

🔴 必加约束：**支付由服务端验证**——客户端只发起请求。

```csharp
// ❌ 危险：客户端算金额
public void OnPurchaseButtonClick() {
    int amount = 99;  // 客户端写死 → 作弊改 0
    _api.PostAsync("/v1/purchase", new { amount, productId });
}

// ✅ 正确：服务端算金额
public void OnPurchaseButtonClick() {
    _api.PostAsync("/v1/purchase", new { productId });  // 只传 productId
    // 服务端查表得金额
}
```

### 7.2 防刷与防退款

- ✅ **支付凭证服务端验证**（不信任客户端回调）
- ✅ **一人一单**（活动期间防刷）
- ✅ **未发货退款**（未成年退款必须执行）

### 7.3 Apple / Google 内购

🔴 必加约束：**内购必须用官方 SDK**（IAP / BillingClient）——不用第三方支付。

```csharp
// iOS 内购
using UnityEngine.Purchasing;
public class IAPManager : IStoreListener {
    public void BuyProduct(string productId) {
        _controller.InitiatePurchase(productId);
    }

    public void OnPurchaseComplete(Product product) {
        // 1. 验证 receipt（服务端验证）
        var receipt = product.receipt;
        StartCoroutine(_api.VerifyReceiptAsync(productId, receipt, OnVerified));
    }

    private void OnVerified(VerifyResult result) {
        if (result.IsValid) {
            // 2. 发放奖励（服务端发放）
            _api.GrantRewardAsync(result.PlayerId, productId);
        }
    }
}
```

服务端验证 receipt：
```csharp
// 服务端伪代码
public async Task<VerifyResult> VerifyReceiptAsync(string productId, string receipt) {
    // 1. 调用 Apple / Google 验证
    var isValid = productId switch {
        "com.example.coin_100" => await AppleVerifyAsync(receipt),
        _ => await GoogleVerifyAsync(receipt)
    };
    if (!isValid) return VerifyResult.Invalid();

    // 2. 检查是否已使用（防重放）
    if (await _redis.ExistsAsync($"receipt:{receipt.GetHash()}"))
        return VerifyResult.Replay();

    // 3. 标记已使用
    await _redis.SetAsync($"receipt:{receipt.GetHash()}", "1", TimeSpan.FromDays(365));

    return VerifyResult.Ok();
}
```

## 8. AI 安全清单

AI 实现 Unity 安全相关功能时，必须按此清单核查：

### 8.1 数据存储

- [ ] Token / API Key 用安全存储（Keychain / Keystore）
- [ ] **不把 Token 写 PlayerPrefs**
- [ ] 存档加密（AES）

### 8.2 反作弊

- [ ] **所有关键判定放服务端**（伤害 / 奖励 / 抽卡 / 支付）
- [ ] 服务端检测异常行为（攻击频率 / 伤害异常）
- [ ] 客户端基础防作弊（仅 Release）：Root 检测 / 调试器检测 / 内存校验

### 8.3 资源保护

- [ ] Asset Bundle 加密
- [ ] **Release 用 IL2CPP**
- [ ] 代码混淆（iXGuard / DexGuard / .NET Reactor）

### 8.4 网络

- [ ] **所有 API 用 HTTPS**
- [ ] 请求签名（HMAC-SHA256 + 时间戳）
- [ ] Token 绑定设备
- [ ] 防重放（nonce + Redis）

### 8.5 隐私

- [ ] 遵守《个人信息保护法》/ GDPR
- [ ] **只收集必要数据**（最小化原则）
- [ ] 用户可导出 / 删除数据
- [ ] 隐私政策明确告知

### 8.6 支付

- [ ] **服务端验证支付凭证**（不信任客户端）
- [ ] 一单一单防刷
- [ ] 用官方 IAP SDK（iOS StoreKit / Google Play Billing）
- [ ] Receipt 一次性（防重放）
- [ ] 未成年退款支持
