# 00 - Unity Qoder 项目入口规则

---

## 1. 使用要求

将本规则在 Qoder 中设为始终生效。执行 Unity 任务前，先读取 `.ai-rules/unity/15-AI通用入口规则.md`，再按 `.ai-rules/unity/00-文档总览.md` 选择当前任务需要的专题规则。

## 2. 执行约束

- 🔴 **必须**检查项目配置、已安装包、程序集、渲染管线、资源系统和同模块已有实现。
- 🔴 **必须**只使用项目已验证可用的 API 与包；不确定时采用已有实现或询问用户。
- ❌ **禁止**臆造资源、依赖、命令、测试结果或项目架构。
- ❌ **禁止**未授权升级依赖、迁移资源系统或进行无关重构。

## 3. 交付要求

说明修改内容、执行的验证、未验证范围与风险。
