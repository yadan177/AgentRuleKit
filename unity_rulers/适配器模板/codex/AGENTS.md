# 00 - Unity Codex 项目入口规则

---

## 1. 任务开始前

执行 Unity 任务前，先阅读 `.ai-rules/unity/15-AI通用入口规则.md`，再按 `.ai-rules/unity/00-文档总览.md` 读取当前任务相关的专题规则。

## 2. 项目事实优先

- 🔴 **必须**检查 `ProjectSettings/ProjectVersion.txt`、`Packages/manifest.json`、程序集、渲染管线、资源系统和同模块既有实现。
- 🔴 **必须**只使用项目已验证可用的 API 与包；不确定时采用已有实现或询问用户。
- ❌ **禁止**臆造资源、依赖、命令、测试结果或项目架构。
- ❌ **禁止**未经授权升级 Unity、依赖、渲染管线、资源系统或进行无关重构。

## 3. 验证与交付

执行与改动相称的现有验证；无法执行时说明原因和风险。交付时说明修改内容、验证结果、未验证范围与需要确认的事项。
