# 00 - Unity AI 项目入口规则

---

## 1. Unity 任务开始前

- 先阅读 `.ai-rules/unity/15-AI通用入口规则.md`。
- 再按 `.ai-rules/unity/00-文档总览.md` 的任务查表读取必要专题规则。
- 检查 `ProjectSettings/ProjectVersion.txt`、`Packages/manifest.json`、asmdef、渲染管线、资源系统和同模块既有实现。

## 2. 执行边界

- 不臆造包、API、资源、测试命令或项目结构。
- 未获授权不升级依赖、不迁移架构或资源系统、不做无关重构。
- 只使用项目已验证可用的 Unity API 与包；不确定时采用已有实现或询问用户。

## 3. 验证与交付

- 执行可用且与改动相称的验证；不能执行时说明原因和风险。
- 交付时说明改动、验证结果、未验证项与需要确认的事项。
