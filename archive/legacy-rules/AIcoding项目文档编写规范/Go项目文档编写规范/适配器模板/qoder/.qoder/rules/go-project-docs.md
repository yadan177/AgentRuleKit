# Go 技术文档 Qoder 入口规则

---

## 1. 使用要求

将本规则设为始终生效。执行 Go 技术文档任务，或 Go 实现任务判断存在文档影响时，读取 `.ai-rules/go-project-docs/其他规则/04-GoAI技术文档任务入口.md` 和 `.ai-rules/go-project-docs/其他规则/01-技术文档组织与维护规范.md`，再按总览选择专题规则。

## 2. 执行约束

- 🔴 必须检查 `go.mod`、包边界、配置、契约、测试、构建和 CI 事实。
- 🔴 必须复用项目已验证的术语与权威来源；不确定时标记待确认或询问用户。
- ❌ 禁止臆造依赖、命令、接口、测试结果或项目架构。

## 3. 交付

说明修改、依据、文档影响结论、验证、未验证范围与风险。
