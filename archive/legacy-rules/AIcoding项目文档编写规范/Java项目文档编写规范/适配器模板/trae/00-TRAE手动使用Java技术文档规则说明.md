# 00 - TRAE 手动使用 Java 技术文档规则说明

---

## 1. 使用方式

未核实当前 TRAE 版本稳定规则路径前，执行技术文档任务或实现任务判断存在文档影响时，请手动附加：

1. `.ai-rules/java-project-docs/其他规则/04-JavaAI技术文档任务入口.md`。
2. `.ai-rules/java-project-docs/其他规则/01-技术文档组织与维护规范.md`。
3. `.ai-rules/java-project-docs/其他规则/00-Java技术文档编写规范总览.md`。
4. 当前任务相关的 Java 专题规则。

TRAE 当前采用手动附加；没有实际附加时不得宣称自动执行了文档门禁。

## 2. 推荐提示词

```text
先检查 JDK、构建文件、模块、配置、契约、数据、测试和部署事实，再完成文档任务。不要臆造框架、依赖、命令或验证结果；未经授权不要升级 JDK、依赖、框架或构建系统。最后报告修改、依据、验证、未验证项与风险。
```

## 3. 后续适配

- 🟡 当前 TRAE 版本的官方资料明确稳定规则路径后，再增加自动加载模板。
- ❌ 在此之前，不要猜测或创建未验证的 TRAE 配置文件。
