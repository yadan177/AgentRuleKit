# 00 - Java 技术文档 Codex 入口规则

## 1. 任务路由

执行 Java 技术文档任务，或 Java 实现任务判断存在文档影响时，读取 `.ai-rules/java-project-docs/其他规则/04-JavaAI技术文档任务入口.md` 和 `.ai-rules/java-project-docs/其他规则/01-技术文档组织与维护规范.md`，再按总览选择专题规则。

## 2. 项目事实优先

- 🔴 必须检查 JDK、构建文件、模块、配置、迁移、契约、测试和部署事实。
- 🔴 必须复用项目已验证的术语与权威来源；不确定时标记待确认或询问用户。
- ❌ 禁止臆造 Spring、Maven、Gradle、ORM、消息系统、命令或验证结果。
