# 00 - Unity Qoder 项目入口规则

---

## 1. 使用要求

将本规则在 Qoder 中设为始终生效。执行 Unity 任务前，先读取 `.ai-rules/unity/15-AI通用入口规则.md`，再按 `.ai-rules/unity/00-文档总览.md` 选择当前任务需要的专题规则。

## 2. 执行约束

- 🔴 **必须**检查项目配置、已安装包、程序集、渲染管线、资源系统和同模块已有实现。
- 🔴 **必须**只使用项目已验证可用的 API 与包；不确定时采用已有实现或询问用户。
- ❌ **禁止**臆造资源、依赖、命令、测试结果或项目架构。
- ❌ **禁止**未授权升级依赖、迁移资源系统或进行无关重构。

## 3. 交付要求

说明修改内容、执行的验证、未验证范围与风险。

## 4. Unity 实现任务的文档影响门禁

- 任何新增、修改或删除 Unity 功能的任务，在开始实现前必须判断技术文档影响。
- 涉及模块、Scene、Prefab、资源加载、程序集、包、配置、数据结构、网络契约、生命周期、构建/平台、术语或验证结论变化时，必须读取 `.ai-rules/unity-project-docs/其他规则/04-UnityAI技术文档任务入口.md` 和 `.ai-rules/unity-project-docs/其他规则/01-技术文档组织与维护规范.md`。
- 受影响文档未同步时不得报告完整完成；无影响时必须说明结论和依据。
- 文档规则缺失或路径不存在时必须报告，不能假装已执行。
