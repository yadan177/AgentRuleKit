# 00 - Java AI 规则适配器使用说明

---

## 1. 目标与原则

本目录提供 Java 规则库的常驻入口。完整执行规则维护在 `java_rulers/` 中；适配器负责触发关键门禁并定位到 [14 - Java AI 通用入口规则](../14-AI通用入口规则.md)。

- 🔴 保留规则正文的现有层级；适配器不得复制整套专题正文。
- 🔴 Codex、Qoder 等自动加载入口必须直接保留简短的文档影响门禁。
- 🟡 规则正文与实际使用的入口配置应一并纳入版本控制。

## 2. 安装模式

| 模式 | 导入内容 | 能力边界 |
|---|---|---|
| 仅编码模式 | Java 开发规则与当前编辑器入口 | 可开发；发现文档影响时只能报告文档规则缺失 |
| 开发—文档闭环模式（推荐） | Java 开发规则、Java 技术文档规则及两个入口 | 实现任务判断文档影响，并在有影响时进入同步流程 |

## 3. 文件映射

| 源内容 | 目标位置 | 说明 |
|---|---|---|
| `AIcoding项目开发规范/java_rulers/00-文档总览.md`、`14-AI通用入口规则.md`、`其他规则/` | `.ai-rules/java/` | Java 开发规则正文 |
| `AIcoding项目文档编写规范/Java项目文档编写规范/其他规则/` | `.ai-rules/java-project-docs/其他规则/` | Java 技术文档规则正文 |
| 开发规则与文档规则各自的 `适配器模板/codex/AGENTS.md` | 项目根 `AGENTS.md` | 仅 Codex；合并而非覆盖 |
| 开发规则 `java-core.md` 与文档规则 `java-project-docs.md` | `.qoder/rules/` 对应文件 | 仅 Qoder；闭环模式下均设为始终生效 |
| 两套规则各自的 TRAE 使用说明 | 不创建未经验证的固定入口 | 仅 TRAE；按任务手动附加 |

三种编辑器入口三选一，规则正文可以共用。

## 4. 安装与验证

1. 按映射复制规则正文。
2. 只安装当前编辑器入口；闭环模式同时安装开发入口和文档入口。
3. Codex 合并两个 `AGENTS.md`；Qoder 复制两个入口并确认始终生效；TRAE 按说明手动附加。
4. 文件检查：入口引用路径和 `00` 至 `04` 文档规则实际存在。
5. 编辑器检查：入口处于当前项目作用域或已经始终生效/手动附加。
6. 行为检查：用最小实现任务确认 AI 能说明已加载入口、文档影响结论和依据。

## 5. 更新与维护

- 🔴 更新规则正文可按映射替换；项目根 `AGENTS.md` 只能合并，不能覆盖已有内容。
- 🔴 修改入口、文件名或路径后，检查三个适配器并重新执行安装验证。
- 🔴 Qoder 更新后复核始终生效状态；TRAE 更新后在下一任务重新附加。
- ❌ 简短门禁只负责触发，不得扩展成第二份完整专题规则。
