# 00 - Python Codex 项目入口规则

---

## 1. 任务路由

执行 Python 任务前，先阅读 `.ai-rules/python/14-AI通用入口规则.md`，再按 `.ai-rules/python/00-文档总览.md` 读取当前任务相关专题规则。

## 2. 项目事实与交付

- 🔴 必须检查 Python 版本、依赖、包边界、配置、测试、构建与部署事实。
- 🔴 只使用项目已验证的 API 与依赖；不确定时复用现有实现或询问用户。
- ❌ 禁止臆造框架、命令、测试结果、接口或项目架构；未经授权不得升级 Python、替换框架或无关重构。
- 🔴 执行与改动相称的验证；无法执行时说明原因、未验证范围与风险。

## Python 实现任务的文档影响门禁

- 🔴 任何新增、修改或删除 Python 功能的任务，在开始实现前必须判断技术文档影响。
- 🔴 涉及包/业务模块、API、数据模型、迁移、鉴权、配置、任务流程、生命周期、部署、术语或验证结论变化时，必须读取 `.ai-rules/python-project-docs/其他规则/04-PythonAI技术文档任务入口.md` 和 `.ai-rules/python-project-docs/其他规则/01-技术文档组织与维护规范.md`。
- 🔴 受影响文档未同步时不得报告完整完成；无影响时必须说明结论和依据。
- 🔴 文档规则缺失或路径不存在时必须报告，不能假装已执行。
