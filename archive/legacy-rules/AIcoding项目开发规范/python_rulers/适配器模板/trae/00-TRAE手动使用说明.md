# 00 - TRAE 手动使用 Python AI 编码规则说明

---

## 1. 使用方式

未核实当前 TRAE 版本稳定的项目规则路径前，请按任务手动附加：

1. `.ai-rules/python/14-AI通用入口规则.md`。
2. `.ai-rules/python/00-文档总览.md`。
3. 当前任务相关的 Python 专题规则。
4. 功能实现任务同时附加 `.ai-rules/python-project-docs/其他规则/04-PythonAI技术文档任务入口.md` 和 `.ai-rules/python-project-docs/其他规则/01-技术文档组织与维护规范.md`。

TRAE 当前采用手动附加；没有实际附加时不得宣称自动执行了文档门禁。

## 2. 推荐提示词

```text
先遵守已附加的 Python AI 通用入口规则；功能实现前判断技术文档影响，有影响时同步，无影响时说明依据。检查 Python 版本、依赖、包结构、配置、测试、构建与部署事实后，再完成当前任务。不要臆造框架、依赖、命令或验证结果；未经授权不要升级 Python、依赖、框架或部署配置。最后报告修改、文档影响、验证、未验证项与风险。
```
