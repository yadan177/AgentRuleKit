# 11 - Unity 编辑器扩展开发规则

> 🟢 本文件适用于 Unity Editor 扩展工具开发（CustomEditor/MenuItem/AssetPostprocessor）。<br>
> 🔴 不适用：业务逻辑实现、运行时性能调优、美术资源制作

---


## 1. CustomEditor（自定义 Inspector）

🔴 **AI 开始前**必须确认目标脚本的程序集边界、Unity 版本、现有 Editor 工具目录和 Inspector 实现。`UnityEditor` 引用必须被隔离在 Editor 专用编译范围内；不得把 Editor API 带入运行时代码。

### 1.1 CustomEditor 基础

**CustomEditor** = 给 `MonoBehaviour` / `ScriptableObject` / 其他 Asset 自定义 Inspector。

**基础用法**：

```csharp
using UnityEngine;
using UnityEditor;

[CustomEditor(typeof(EnemyConfig))]
public class EnemyConfigEditor : Editor
{
    public override void OnInspectorGUI()
    {
        // 1. 画默认 Inspector
        DrawDefaultInspector();

        // 2. 加自定义内容
        var config = (EnemyConfig)target;

        EditorGUILayout.Space();
        EditorGUILayout.LabelField("统计", EditorStyles.boldLabel);
        EditorGUILayout.LabelField("攻击力", config.AttackDamage.ToString());
        EditorGUILayout.LabelField("生命值", config.MaxHealth.ToString());

        // 3. 自动刷新（每帧重绘）
        if (Application.isPlaying)
            Repaint();
    }
}
```

**关键点**：

- 🔴 **`[CustomEditor(typeof(T))]`** —— 必须指定要扩展的类型
- 🔴 **继承 `Editor`** —— 必须继承 UnityEditor.Editor
- 🔴 **override `OnInspectorGUI()`** —— 自定义 Inspector 内容
- 🔴 **放入 Editor 专用编译范围** —— 可使用 `Assets/Editor/`，或在项目已有的 Editor-only asmdef 中隔离，确保代码不进入运行时包。
- 🟡 `DrawDefaultInspector()` —— 显示默认字段（部分自定义时用）

**Editor 文件位置**：

```text
Assets/
└── Editor/                              # 🆕 Editor 代码目录
    ├── EnemyConfigEditor.cs            # 自定义 Inspector
    ├── Tools/
    │   └── LevelBuilderWindow.cs       # 自定义窗口
    └── PropertyDrawers/
        └── ReadOnlyDrawer.cs            # 自定义属性绘制
```

### 1.2 PropertyDrawer 自定义属性绘制

**PropertyDrawer** = 给 `[SerializeField]` 字段自定义 Inspector 显示（基于属性）。

**示例**：自定义 `[ReadOnly]` 属性让字段在 Inspector 不可编辑：

```csharp
// ReadOnlyAttribute.cs — 运行时程序集可见，不引用 UnityEditor
using UnityEngine;

public class ReadOnlyAttribute : PropertyAttribute { }
```

```csharp
// ReadOnlyDrawer.cs — 必须位于 Editor 文件夹或仅 Editor 平台的 asmdef
using UnityEditor;
using UnityEngine;

[CustomPropertyDrawer(typeof(ReadOnlyAttribute))]
public class ReadOnlyDrawer : PropertyDrawer
{
    public override void OnGUI(Rect position, SerializedProperty property, GUIContent label)
    {
        EditorGUI.BeginDisabledGroup(true);
        EditorGUI.PropertyField(position, property, label, true);
        EditorGUI.EndDisabledGroup();
    }
}
```

```csharp
// Player.cs
public class Player : MonoBehaviour
{
    [ReadOnly] [SerializeField] private int m_id;  // Inspector 不可编辑
}
```

**🔴 关键点**：

- 🔴 **`[CustomPropertyDrawer(typeof(MyAttribute))]`** —— 必须指定属性类型
- 🔴 **继承 `PropertyDrawer`** —— 必须继承
- 🔴 **override `OnGUI(Rect, SerializedProperty, GUIContent)`** —— 必须实现
- 🔴 **PropertyDrawer 文件也要放入 Editor 专用编译范围**
- 🔴 **PropertyDrawer 与 CustomEditor 配合**：CustomEditor 用 `DrawDefaultInspector` 时，PropertyDrawer 自动生效

**实战 PropertyDrawer 示例**：

| 需求 | 实现 |
|------|------|
| 字段只读 | `[ReadOnly]` |
| 字段必填（非空校验）| `[Required]` |
| 字段范围（min/max 滑块）| `[Range(0, 100)]` |
| 字段显示为按钮 | `[Button]`（点击触发方法）|
| 字段显示为下拉 | `[Dropdown]` |

### 1.3 Editor 工具常见用法

**Reset / Header / Tooltip / ContextMenu**（基础 Inspector 增强）：

```csharp
public class Weapon : MonoBehaviour
{
    [Header("基础属性")]
    [Tooltip("武器名称（用于 UI 显示）")]
    [SerializeField] private string m_name = "Sword";

    [Range(0, 100)]
    [SerializeField] private int m_damage = 10;

    [Header("运行时")]
    [SerializeField] private GameObject m_effectPrefab;

    [ContextMenu("重置为默认值")]
    private void ResetToDefaults()
    {
        m_name = "Sword";
        m_damage = 10;
#if UNITY_EDITOR
        UnityEditor.EditorUtility.SetDirty(this);
#endif
    }

    [ContextMenu("测试伤害")]
    private void TestDamage()
    {
        ProjectLog.Write(LogLevel.Debug, "Editor.Tool", $"测试伤害：{m_damage}", this); // 替换为项目真实日志门面
    }
}
```

**常用属性**（AI 给字段加属性时查）：

| 属性 | 用途 | 示例 |
|------|------|------|
| `[Header("X")]` | Inspector 分组标题 | `[Header("基础属性")]` |
| `[Tooltip("X")]` | 鼠标悬停提示 | `[Tooltip("武器名称")]` |
| `[Range(min, max)]` | 滑块范围 | `[Range(0, 100)]` |
| `[SerializeField]` private | 私有字段显示在 Inspector | 见 01-代码编写规则 |
| `[HideInInspector]` | 公有字段不显示 | `[HideInInspector] public int x;` |
| `[ContextMenu("X")]` | 字段 / 方法右键菜单 | 见上方 |
| `[Space]` | 字段间距 | `[Space] [SerializeField] int x;` |
| `[Min(0)]` / `[Max(100)]` | 最小 / 最大值 | `[Min(0)] [SerializeField] int hp;` |
| `[Multiline]` | 多行文本 | `[Multiline] [SerializeField] string note;` |
| `[TextArea]` | 可伸缩文本框 | `[TextArea] [SerializeField] string desc;` |
| `[FormerlySerializedAs("X")]` | 重命名字段保留序列化 | 数据迁移 |

**AI 写字段时**：

- 🔴 **公有字段加 `[SerializeField]`**（01 文档规则）
- 🟡 **字段分组用 `[Header]`**（按业务分类）
- 🟡 **字段加 `[Tooltip]`**（鼠标悬停提示）
- 🟡 **数值字段用 `[Range]` / `[Min]`**（避免 Inspector 输入非法值）
- 🟡 **运行时不可改的字段加 `[ReadOnly]`**（自定义属性 + 1.2 节）


## 2. EditorWindow（自定义窗口）

### 2.1 EditorWindow 基础

**EditorWindow** = 自定义的 Editor 窗口（如工具窗口、调试窗口）。

**基础用法**：

```csharp
using UnityEngine;
using UnityEditor;

public class LevelBuilderWindow : EditorWindow
{
    [MenuItem("Tools/Level Builder")]
    public static void Open()
    {
        // 创建 / 显示窗口
        GetWindow<LevelBuilderWindow>("Level Builder");
    }

    private void OnGUI()
    {
        EditorGUILayout.LabelField("Level Builder", EditorStyles.boldLabel);
        // ... 自定义内容
    }
}
```

**关键点**：

- 🔴 **提供与项目一致的发现入口** —— 常见方式是 `[MenuItem("Tools/...")]`，也可沿用项目已有菜单、Inspector 或工具面板入口。
- 🔴 **继承 `EditorWindow`** —— 必须继承
- 🔴 **override `OnGUI()`** —— 自定义窗口内容
- 🔴 **放入 Editor 专用编译范围**
- 🟡 `GetWindow<T>()` —— 获取 / 创建窗口实例

### 2.2 常用控件（GUILayout）

**Layout 自动布局**（最常用）：

```csharp
private void OnGUI()
{
    // 标题
    EditorGUILayout.LabelField("标题", EditorStyles.boldLabel);

    // 文本输入
    m_name = EditorGUILayout.TextField("名称", m_name);

    // 数值输入
    m_count = EditorGUILayout.IntField("数量", m_count);
    m_speed = EditorGUILayout.FloatField("速度", m_speed);

    // 布尔
    m_enabled = EditorGUILayout.Toggle("启用", m_enabled);

    // 枚举下拉
    m_mode = (Mode)EditorGUILayout.EnumPopup("模式", m_mode);

    // 按钮
    if (GUILayout.Button("执行操作"))
    {
        DoSomething();
    }

    // 分隔线
    EditorGUILayout.Space();
    EditorGUILayout.LabelField("---", EditorStyles.centeredGreyMiniLabel);

    // 列表
    m_scroll = EditorGUILayout.BeginScrollView(m_scroll);
    foreach (var item in m_items)
    {
        EditorGUILayout.LabelField(item);
    }
    EditorGUILayout.EndScrollView();
}
```

**常用控件**：

| 控件 | 用途 |
|------|------|
| `LabelField` | 文字标签 |
| `TextField` / `TextArea` | 文本输入 |
| `IntField` / `FloatField` | 数值输入 |
| `Toggle` | 布尔 |
| `EnumPopup` | 枚举下拉 |
| `ObjectField` | Unity Object 拖入引用 |
| `Button` | 按钮 |
| `BeginScrollView` | 滚动视图 |
| `BeginHorizontal` / `BeginVertical` | 水平 / 垂直布局 |
| `HelpBox` | 帮助提示框 |
| `Foldout` | 折叠组 |

**AI 写 Editor 窗口时**：

- 🔴 **用 GUILayout 控件**（自动布局，比 GUI 简单）
- 🟡 **按钮操作前先检查**（如选中 GameObject / 资源）
- 🟡 **用 `Undo.RecordObject` 记录撤销**（用户可以 Ctrl+Z 撤销）

### 2.3 工具窗口模式

**EditorWindow 类型**：

| 模式 | 用途 | 示例 |
|------|------|------|
| `EditorWindow` 默认 | 通用工具窗口 | `Tools/Level Builder` |
| `EditorWindow + UIElements` | Unity 2022+ UI Toolkit 窗口 | 现代风格 |
| `PopupWindow` | 临时弹窗（无标题栏）| 浮动小窗口 |
| `ScriptableWizard` | 向导式窗口（旧式，已不推荐）| 弃用 |

**示例**（基础 EditorWindow）：

```csharp
public class DebugWindow : EditorWindow
{
    private Vector2 m_scroll;
    private string m_filter = "";

    [MenuItem("Tools/Debug Window")]
    public static void Open() => GetWindow<DebugWindow>("Debug");

    private void OnGUI()
    {
        m_filter = EditorGUILayout.TextField("Filter", m_filter);

        m_scroll = EditorGUILayout.BeginScrollView(m_scroll);
        // 列出所有匹配的对象
        var objects = GameObject.FindObjectsOfType<MonoBehaviour>();
        foreach (var obj in objects)
        {
            if (string.IsNullOrEmpty(m_filter) ||
                obj.name.ToLower().Contains(m_filter.ToLower()))
            {
                EditorGUILayout.ObjectField("Object", obj, typeof(MonoBehaviour), true);
            }
        }
        EditorGUILayout.EndScrollView();
    }
}
```


## 3. MenuItem（菜单项）

### 3.1 顶层菜单

**MenuItem** = 注册 Unity Editor 菜单项。

**基础用法**：

```csharp
using UnityEditor;

// 顶层菜单 Tools / My Tool
[MenuItem("Tools/My Tool")]
private static void OpenMyTool()
{
    OpenMyToolWindow();
}
```

**菜单路径规则**：

| 路径 | 显示位置 |
|------|---------|
| `Tools/...` | 顶部 Tools 菜单 |
| `Assets/...` | Project 窗口右键 |
| `GameObject/...` | Hierarchy 窗口右键 |
| `Component/...` | 顶部 Component 菜单 |
| `Window/...` | 顶部 Window 菜单 |
| `Edit/...` | 顶部 Edit 菜单 |

### 3.2 资产 / 层级菜单（右键菜单）

**资产菜单**（Project 窗口右键）：

```csharp
// 当选中 ScriptableObject 时显示
[MenuItem("Assets/My Tools/Init Settings")]
private static void InitSettings()
{
    // 在 Project 窗口右键 ScriptableObject → My Tools → Init Settings
}
```

**层级菜单**（Hierarchy 窗口右键）：

```csharp
// 当选中 GameObject 时显示
[MenuItem("GameObject/My Tools/Spawn Enemy", false, 10)]
private static void SpawnEnemy()
{
    // 在 Hierarchy 窗口右键 GameObject → My Tools → Spawn Enemy
}
```

### 3.3 快捷键

**MenuItem 可绑定快捷键**：

```csharp
// % = Ctrl (Windows) / Cmd (Mac)
// # = Shift
// & = Alt
// _ = 字母（无修饰键）

[MenuItem("Tools/Save %&s")]  // Ctrl+Alt+S
private static void SaveWithShortcut() { }

[MenuItem("Tools/Quick Action #g")]  // Shift+G
private static void QuickAction() { }
```

**常用快捷键约定**：

| 操作 | 快捷键 |
|------|-------|
| Save | `Ctrl+S` (`%s`) |
| Build | `Ctrl+Shift+B` (`%#b`) |
| Run | `Ctrl+P` (`%p`) |

### 3.4 菜单验证

**`MenuItem` 第三参数**：菜单显示顺序（数字越小越靠前）。

**`MenuItem` 第二参数**：是否启用（true/false 控制菜单是否可点击）。

```csharp
// 在 Tools 菜单的 My Tools 位置显示，优先级 10（在最上面）
[MenuItem("Tools/My Tools/Action", true, 10)]
private static bool ValidateAction()
{
    // 返回 true → 菜单项可点击；false → 菜单项灰显
    return Selection.activeGameObject != null;
}

[MenuItem("Tools/My Tools/Action", false, 10)]
private static void DoAction()
{
    // 实际执行
}
```

**AI 写菜单项时**：

- 🔴 **菜单路径用 `Tools/...` 开头**（统一放 Tools 菜单下）
- 🟡 **用快捷键绑定常用操作**（节省点击时间）
- 🟡 **加验证方法**（菜单项不总是可点）
