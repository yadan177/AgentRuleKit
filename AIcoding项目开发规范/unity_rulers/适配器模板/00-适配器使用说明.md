# 00 - Unity AI 规则适配器使用说明

---

## 1. 目标与原则

本目录提供 Unity 规则库的常驻入口。完整执行规则维护在 `unity_rulers/`；适配器负责触发关键门禁并定位到 [15 - Unity AI 通用入口规则](../15-AI通用入口规则.md)。

- 🔴 适配器不得复制整套专题正文。
- 🔴 Codex、Qoder 等自动加载入口必须直接保留简短的文档影响门禁。
- 🟡 规则正文与实际使用的入口配置应一并纳入版本控制。

## 2. 安装模式

| 模式 | 导入内容 | 能力边界 |
|---|---|---|
| 仅编码模式 | Unity 开发规则与当前编辑器入口 | 可开发；发现文档影响时只能报告文档规则缺失 |
| 开发—文档闭环模式（推荐） | Unity 开发规则、Unity 技术文档规则及两个入口 | 脚本、Scene、Prefab、包、配置等变化可触发文档同步 |

## 3. 文件映射

| 源内容 | 目标位置 | 说明 |
|---|---|---|
| `AIcoding项目开发规范/unity_rulers/00-文档总览.md`、`15-AI通用入口规则.md`、`其他规则/` | `.ai-rules/unity/` | Unity 开发规则正文 |
| `AIcoding项目文档编写规范/Unity项目文档编写规范/其他规则/` | `.ai-rules/unity-project-docs/其他规则/` | Unity 技术文档规则正文 |
| 两套规则各自的 `适配器模板/codex/AGENTS.md` | 项目根 `AGENTS.md` | 仅 Codex；合并而非覆盖 |
| 开发规则 `unity-core.md` 与文档规则 `unity-project-docs.md` | `.qoder/rules/` 对应文件 | 仅 Qoder；闭环模式下均设为始终生效 |
| 两套规则各自的 TRAE 使用说明 | 不创建未经验证的固定入口 | 仅 TRAE；按任务手动附加 |

三种编辑器入口三选一，规则正文可以共用。

## 4. 安装与验证

1. 按映射复制规则正文，只安装当前编辑器入口；闭环模式同时安装开发与文档入口。
2. Codex 合并两个 `AGENTS.md`；Qoder 确认两个入口始终生效；TRAE 按说明手动附加。
3. 检查入口路径与项目作用域，并用最小 Unity 实现任务验证已加载入口、文档影响结论和依据。
4. 行为验证不等同于 Unity Editor、目标平台或真机验证；具体能力仍按项目规则验收。

## 5. 更新与维护

- 🔴 更新项目根 `AGENTS.md` 时只能合并；移动入口或专题文件后更新全部路径。
- 🔴 Qoder 更新后复核始终生效状态；TRAE 更新后重新附加。
- 🔴 路径、文件名或调用链变化后重新执行文件、编辑器和行为三层验证。
- ❌ 简短门禁只负责触发，不得扩展成第二份完整规则。
