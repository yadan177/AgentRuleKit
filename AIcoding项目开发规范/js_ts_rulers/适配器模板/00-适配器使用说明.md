# 00 - JS / TS AI 规则适配器使用说明

---

## 1. 目标与原则

本目录提供 JS/TS 规则库的常驻入口。完整规则维护在 `js_rulers/` 与 `ts_rulers/`；TypeScript 项目先执行 JS 运行时基线，再追加 TS 类型专题。

- 🔴 适配器不得复制整套专题正文。
- 🔴 Codex、Qoder 等自动加载入口必须直接保留简短的文档影响门禁。
- 🔴 只有实际使用 TypeScript 的项目才复制并加载 TS 规则。

## 2. 安装模式

| 模式 | 导入内容 | 能力边界 |
|---|---|---|
| 仅编码模式 | JS 规则；TS 项目再加 TS 规则；当前编辑器开发入口 | 可开发；发现文档影响时只能报告文档规则缺失 |
| 开发—文档闭环模式（推荐） | 开发规则、JS+TS 技术文档规则及两个入口 | 实现任务判断并同步受影响技术文档 |

## 3. 文件映射

| 源内容 | 目标位置 | 说明 |
|---|---|---|
| `AIcoding项目开发规范/js_ts_rulers/js_rulers/` | `.ai-rules/js/` | 所有 JS/TS 项目的运行时基线 |
| `AIcoding项目开发规范/js_ts_rulers/ts_rulers/` | `.ai-rules/ts/` | 仅 TypeScript 项目 |
| `AIcoding项目文档编写规范/JS+TS项目文档编写规范/其他规则/` | `.ai-rules/js-ts-project-docs/其他规则/` | 技术文档规则正文 |
| 两套规则各自的 `适配器模板/codex/AGENTS.md` | 项目根 `AGENTS.md` | 仅 Codex；合并而非覆盖 |
| 开发规则 `js-ts-core.md` 与文档规则 `js-ts-project-docs.md` | `.qoder/rules/` 对应文件 | 仅 Qoder；闭环模式下均设为始终生效 |
| 两套规则各自的 TRAE 使用说明 | 不创建未经验证的固定入口 | 仅 TRAE；按任务手动附加 |

三种编辑器入口三选一，规则正文可以共用。

## 4. 安装与验证

1. 复制 JS 基线；检测到 `tsconfig*.json`、`.ts`/`.tsx` 或 TS 构建配置时再复制 TS 规则。
2. 只安装当前编辑器入口；闭环模式同时安装开发入口和文档入口。
3. Codex 合并两个 `AGENTS.md`；Qoder 确认两个入口始终生效；TRAE 按说明手动附加。
4. 检查文件、编辑器作用域，并用最小实现任务验证已加载入口、文档影响结论及依据。

## 5. 更新与维护

- 🔴 修改 JS 15、TS 09 或技术文档入口后，检查三个适配器路径。
- 🔴 更新项目根 `AGENTS.md` 时只能合并；Qoder 更新后复核始终生效；TRAE 更新后重新附加。
- 🔴 路径、文件名或调用链变化后重新执行文件、编辑器和行为三层验证。
- ❌ 简短门禁只负责触发，不得扩展成第二份完整规则。
