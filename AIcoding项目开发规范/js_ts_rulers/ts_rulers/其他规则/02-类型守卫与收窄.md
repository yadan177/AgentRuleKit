# 02 - TypeScript 类型守卫与收窄

> 🟢 本文件适用于 TypeScript 运行时类型收窄（`typeof` / `instanceof` / 自定义守卫 / 项目已选用的运行时 schema）。<br>
> 🔴 不适用：业务逻辑实现、UI 样式设计

---

## 1. 🔴 硬约束 · 这些绝对不要写

### 1.1 `as` 逃避类型检查

```ts
// ❌ 双断言（绕过所有检查）
const value = unknownValue as unknown as User;

// ❌ JSON.parse + as（跳过校验）
const user = JSON.parse(input) as User;

// ✅ 若项目已使用 zod，可用 schema 做运行时校验；否则复用已有 schema 或自定义守卫
import { z } from 'zod';
const UserSchema = z.object({ id: z.number(), name: z.string() });
const user = UserSchema.parse(JSON.parse(input));    // 校验失败抛错
```

**若项目已启用 typescript-eslint 的类型化规则，可配置**：

```js
{
  rules: {
    '@typescript-eslint/no-unsafe-argument': 'error',
    '@typescript-eslint/no-unsafe-assignment': 'error',
    '@typescript-eslint/no-unsafe-call': 'error',
    '@typescript-eslint/no-unsafe-member-access': 'error',
    '@typescript-eslint/no-unsafe-return': 'error',
  },
}
```

### 1.2 `!` 非空断言滥用

```ts
// ❌
function getUser(id: number) {
  return users.find(u => u.id === id)!.name;        // 不存在就抛运行时错
}

// ✅ 显式 null 检查
function getUser(id: number): string {
  const user = users.find(u => u.id === id);
  if (!user) throw new Error(`User ${id} not found`);
  return user.name;
}

// ✅ 可选链 + 空值合并
function getUserName(id: number): string {
  return users.find(u => u.id === id)?.name ?? 'Unknown';
}
```

**ESLint 强制**：

```js
{
  rules: {
    '@typescript-eslint/no-non-null-assertion': 'error',
  },
}
```

**例外**：与有类型守卫的代码配合时可以用 `!`，必须**注释说明**：

```ts
// 已通过 zod 校验，name 一定存在
const name = UserSchema.parse(input).name!;          // ❌ 仍避免
```

### 1.3 unknown 没收窄就用

```ts
// ❌
function process(input: unknown) {
  return input.name;                                  // 编译报错
}

// ✅ typeof + 属性检查
function process(input: unknown) {
  if (
    typeof input === 'object' &&
    input !== null &&
    'name' in input &&
    typeof (input as Record<string, unknown>).name === 'string'
  ) {
    return (input as { name: string }).name;
  }
  throw new Error('Invalid input');
}

// ✅ zod（推荐）
const UserSchema = z.object({ name: z.string() });
const user = UserSchema.parse(input);
```

### 1.4 catch 子句用 any

```ts
// ❌
try { /* ... */ } catch (e: any) { console.log(e.message); }

// ✅ catch 用 unknown + instanceof 收窄（TS 4.4+）
try { /* ... */ }
catch (e: unknown) {
  if (e instanceof Error) {
    logger.error(e.message);
  } else {
    logger.error('Unknown error', e);
  }
}
```

### 1.5 `filter` 后误以为类型已经收窄

```ts
const users: Array<User | undefined> = getUsers();

// ❌ 只判断活跃状态不足以排除 undefined；结果仍可能包含 undefined
const validUsers = users.filter(u => u?.isActive);

// ✅ 需要排除 undefined 时，写出与运行时条件一致的类型谓词
const activeUsers = users.filter((u): u is User => u?.isActive === true);
```

**复用类型谓词**：

```ts
function isActiveUser(user: User): user is User & { isActive: true } {
  return user.isActive === true;
}
const validUsers = users.filter(isActiveUser);
```

### 1.6 判别联合没利用

```ts
type Shape =
  | { kind: 'rect'; width: number; height: number }
  | { kind: 'circle'; radius: number };

function area(s: Shape): number {
  // ❌ 不写 discriminator 字段就没法收窄
  if ('width' in s) {
    return s.width * s.height;                       // ❌ 'height' 不在类型里
  }
  return Math.PI * s.radius ** 2;
}

// ✅ 用 kind / type 字段做 discriminator
function area(s: Shape): number {
  switch (s.kind) {
    case 'rect': return s.width * s.height;
    case 'circle': return Math.PI * s.radius ** 2;
  }
}

// ✅ 加 never 保证 exhaustive
function assertNever(x: never): never {
  throw new Error('Unknown shape: ' + JSON.stringify(x));
}
function area(s: Shape): number {
  switch (s.kind) {
    case 'rect': return s.width * s.height;
    case 'circle': return Math.PI * s.radius ** 2;
    default: return assertNever(s);                  // 漏 case 编译报错
  }
}
```

## 2. 🟡 推荐 · 团队约定

### 2.1 typeof 收窄（基本类型）

```ts
typeof x === 'string'         // string
typeof x === 'number'         // number
typeof x === 'boolean'        // boolean
typeof x === 'undefined'      // undefined
typeof x === 'symbol'         // symbol
typeof x === 'bigint'         // bigint
typeof x === 'function'       // function
typeof x === 'object'         // object | null
```

### 2.2 instanceof 收窄（class）

```ts
class Dog { bark() {} }
class Cat { meow() {} }

function speak(animal: Dog | Cat) {
  if (animal instanceof Dog) {
    animal.bark();
  } else {
    animal.meow();
  }
}
```

**注意**：跨 realm / iframe 时 `instanceof` 不可靠。

### 2.3 in 操作符（属性存在）

```ts
interface Bird { fly(): void }
interface Fish { swim(): void }

function move(animal: Bird | Fish) {
  if ('fly' in animal) {
    animal.fly();
  } else {
    animal.swim();
  }
}
```

### 2.4 自定义类型谓词函数

```ts
interface User { id: number; name: string }

function isUser(value: unknown): value is User {
  return (
    typeof value === 'object' &&
    value !== null &&
    'id' in value &&
    typeof (value as Record<string, unknown>).id === 'number' &&
    'name' in value &&
    typeof (value as Record<string, unknown>).name === 'string'
  );
}

const data: unknown = JSON.parse(input);
if (isUser(data)) {
  console.log(data.name);                             // 类型是 User
}
```

**复用谓词**：优先复用项目既有的 schema/校验库；没有依赖时，小而透明的自定义守卫通常更合适。不要仅为本节示例新增校验依赖。

### 2.5 satisfies vs as 边界

```ts
// satisfies：校验形状 + 保留字面量
const colors = {
  red: '#f00',
  green: '#0f0',
} satisfies Record<string, string>;
colors.red;                                            // 类型 '#f00'

// as：强制断言（最后手段）
const value = something as User;                      // 用在已确认类型但 TS 推断不出
```

**优先级**：外部数据优先运行时 schema 或自定义守卫；`satisfies` 只校验编译期形状；`as` 仅用于已有运行时证据但编译器无法表达的边界。

### 2.6 运行时 schema 校验（外部数据）

若项目已使用 zod，下面是一个示例；使用其他 schema 库或自定义守卫时，保持相同的输入边界与错误处理语义，不要因示例新增依赖。

```ts
import { z } from 'zod';

const UserSchema = z.object({
  id: z.number().int().positive(),
  name: z.string().min(1).max(50),
  email: z.string().email(),
  age: z.number().int().min(0).max(150).optional(),
});

type User = z.infer<typeof UserSchema>;                // 自动推导类型

// 校验失败抛错
const user = UserSchema.parse(await fetchUser(1));

// 校验失败返结果（不抛错）
const result = UserSchema.safeParse(input);
if (result.success) {
  console.log(result.data.name);
} else {
  console.error(result.error.issues);
}
```

来自 API、`localStorage`、URL 参数或其他不受当前类型系统控制的数据，必须在信任边界完成与风险相称的运行时校验；TypeScript 类型本身不会校验运行时值。

## 3. 🟢 可选 · 视情况

### 3.1 品牌类型（branded type）

模拟 nominal typing（区分"看起来一样的不同类型"）：

```ts
type UserId = string & { readonly __brand: 'UserId' };
type OrderId = string & { readonly __brand: 'OrderId' };

function getUser(id: UserId) { /* ... */ }

const userId = '123' as UserId;                       // 强制断言
const orderId = '456' as OrderId;
getUser(userId);                                       // ✅
getUser(orderId);                                      // ❌ 编译报错
```

### 3.2 assertion function

```ts
function assertIsUser(value: unknown): asserts value is User {
  if (!isUser(value)) throw new Error('Not a user');
}

const data: unknown = JSON.parse(input);
assertIsUser(data);                                    // 之后 data 类型是 User
console.log(data.name);                                // ✅
```
