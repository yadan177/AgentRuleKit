# 04 - TypeScript 高级类型

> 🟢 本文件适用于 TypeScript 高级类型的使用边界（条件类型/infer/映射类型/模板字面量）。<br>
> 🔴 不适用：业务逻辑实现（仅库 / 抽象层使用）

---

## 1. 🔴 硬约束 · 这些绝对不要写

### 1.1 业务代码过度使用高级类型

```ts
// ❌ 业务代码用条件类型 + infer + 映射类型
type GetFieldType<T, K extends keyof T> = T[K] extends infer R ? R : never;
function processEntity<T, K extends keyof T>(entity: T, field: K): GetFieldType<T, K> {
  return entity[field];
}

// ✅ 业务代码用简单泛型
function processEntity<T, K extends keyof T>(entity: T, field: K): T[K] {
  return entity[field];
}
```

**判断标准**：业务代码读不懂 = 维护灾难。同事需要先学一遍 TS 类型体操才能 review。

### 1.2 自己造轮子（重复实现内置工具类型）

```ts
// ❌
type MyPartial<T> = { [K in keyof T]?: T[K] };          // 与 Partial 重复
type MyPick<T, K extends keyof T> = { [P in K]: T[P] }; // 与 Pick 重复
type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : any;  // 与 ReturnType 重复

// ✅ 用内置（详见 [01 §硬约束 7](./01-类型系统.md)）
type UserOptional = Partial<User>;
type UserNameOnly = Pick<User, 'name'>;
type FnReturn = ReturnType<typeof myFn>;
```

### 1.3 条件类型分支覆盖不全

```ts
// ❌ 缺少 false 分支
type Wrap<T> = T extends string ? { value: T } : unknown;     // 非 string 全部变 unknown

// ✅ false 分支也要写
type Wrap<T> = T extends string ? { value: T } : T extends number ? { value: T } : never;

// ✅ 用 never 兜底
type Wrap<T> = T extends string | number ? { value: T } : never;
```

### 1.4 递归类型无终止条件

```ts
// ❌ 无终止条件（可能无限循环）
type DeepReadonly<T> = {
  [K in keyof T]: T[K] extends object ? DeepReadonly<T[K]> : T[K];
};

// ✅ 加终止（object + 已知基本类型）
type DeepReadonly<T> = T extends Function | string | number | boolean | null | undefined
  ? T
  : { readonly [K in keyof T]: DeepReadonly<T[K]> };
```

**库代码也要谨慎**——给标准库用。

## 2. 🟡 推荐 · 团队约定

### 2.1 条件类型（Conditional Types）

**语法**：`T extends U ? X : Y`

```ts
type IsString<T> = T extends string ? true : false;
type A = IsString<string>;                              // true
type B = IsString<number>;                              // false

// 提取 Promise 的内层类型
type Awaited<T> = T extends Promise<infer U> ? U : T;
type A = Awaited<Promise<string>>;                      // string
```

### 2.2 infer 关键字

```ts
// 函数返回类型
type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : never;
type Fn = () => number;
type R = MyReturnType<Fn>;                              // number

// 数组元素类型
type ElementOf<T> = T extends (infer U)[] ? U : never;
type E = ElementOf<string[]>;                           // string

// Promise 内层
type PromiseInner<T> = T extends Promise<infer U> ? U : T;
type I = PromiseInner<Promise<number>>;                 // number
```

**infer 位置**：只能在 `extends` 子句的**真分支**。

### 2.3 映射类型（Mapped Types）

**基本语法**：`{ [K in keyof T]: ... }`

```ts
// 全字段可选
type MyPartial<T> = { [K in keyof T]?: T[K] };

// 重命名 + 过滤
type Stringify<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

interface User { id: number; name: string; }
type UserGetters = Stringify<User>;
// { getId: () => number; getName: () => string }
```

**修饰符**：`readonly` / `?` / `-readonly` / `-?`

```ts
type ReadonlyUser = { readonly [K in keyof User]: User[K] };
type Mutable<T> = { -readonly [K in keyof T]: T[K] };
type Required<T> = { [K in keyof T]-?: T[K] };
```

### 2.4 模板字面量类型

```ts
type EventName = `on${Capitalize<string>}`;             // 'onClick' | 'onHover' | ...
type ApiPath = `/api/${string}`;                        // 路径约束
type CssUnit = `${number}${'px' | 'rem' | '%'}`;        // '12px' | '12rem' | '12%'
```

### 2.5 内置工具类型原理（理解而非重新实现）

| 类型 | 原理 |
|------|------|
| `Partial<T>` | `{ [K in keyof T]?: T[K] }` |
| `Required<T>` | `{ [K in keyof T]-?: T[K] }` |
| `Readonly<T>` | `{ readonly [K in keyof T]: T[K] }` |
| `Pick<T, K>` | `{ [P in K]: T[P] }` |
| `Omit<T, K>` | `Pick<T, Exclude<keyof T, K>>` |
| `Record<K, V>` | `{ [P in K]: V }` |
| `Exclude<T, U>` | `T extends U ? never : T`（分布式） |
| `Extract<T, U>` | `T extends U ? T : never`（分布式） |
| `ReturnType<T>` | `T extends (...args: any[]) => infer R ? R : never` |
| `Parameters<T>` | `T extends (...args: infer P) => any ? P : never` |
| `InstanceType<T>` | `T extends new (...args: any[]) => infer R ? R : any` |
| `Awaited<T>` | `T extends Promise<infer U> ? Awaited<U> : T` |

### 2.6 分布式条件类型

```ts
// 联合类型进入条件类型会自动 distributive
type ToArray<T> = T extends any ? T[] : never;
type A = ToArray<string | number>;                      // string[] | number[]

// ❌ 想保留 union 时别 distributive
type WithoutDistribute<T> = [T] extends [any] ? T[] : never;
type B = WithoutDistribute<string | number>;            // (string | number)[]
```

## 3. 🟢 可选 · 视情况（库 / 抽象层用）

### 3.1 类型层级（Type Hierarchy）

```
unknown                              ← 顶层（接受一切）
  ├─ any                              ← 旁路（跳过类型检查）
  └─ {} (object)
        ├─ object (non-primitive)
        ├─ string / number / boolean / bigint / symbol
        │     ├─ string literals ("foo")
        │     └─ number literals (42)
        ├─ void (undefined-only)
        └─ null
never                                ← 底层（无值）
```

**赋值规则**：下层可赋给上层，反之不可（除 `any`）。

### 3.2 同名（Homomorphic）映射类型

保留修饰符：

```ts
type ReadonlyUser = { readonly [K in keyof User]: User[K] };  // 继承 readonly
type MutableUser = { -readonly [K in keyof ReadonlyUser]: ReadonlyUser[K] };
```

### 3.3 索引访问类型

```ts
type User = { profile: { name: string; age: number } };
type Name = User['profile']['name'];                    // string
type Profile = User['profile'];                         // { name: string; age: number }
```

### 3.4 const 断言 + 模板字面量组合

```ts
const routes = {
  home: '/',
  users: '/users',
  userDetail: '/users/:id',
} as const;
type Route = typeof routes[keyof typeof routes];         // '/' | '/users' | '/users/:id'

function navigate(route: Route) { /* ... */ }
navigate('/users');                                     // ✅
navigate('/unknown');                                   // ❌
```
