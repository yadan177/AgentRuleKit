# 01 - JavaScript 代码编写规则

> 🟢 本文件适用于 JavaScript / Node.js 代码的基础语法与写法约束。<br>
> 🔴 不适用：项目级架构决策、第三方库深度用法、构建工具配置

---

## 1. 🔴 硬约束 · 这些绝对不要写

### 1.1 命名规范（变量 / 函数 / 类 / 常量 / 文件）

**变量 / 函数 / 方法**：`camelCase`

```js
// ✅
const userName = 'alice';
function getUserById(id) { /* ... */ }

// ❌
const user_name = 'alice';          // Python 风格
const UserName = 'alice';           // 误用 PascalCase
```

**类 / 构造函数 / React 组件**：`PascalCase`

```js
// ✅
class UserService { /* ... */ }
function UserCard({ name }) { /* ... */ }

// ❌
class userService { /* ... */ }
```

**常量（编译期不变的真值）**：`UPPER_SNAKE_CASE`

```js
// ✅
const MAX_RETRY_COUNT = 3;
const API_BASE_URL = 'https://api.example.com';

// ❌
const maxRetryCount = 3;            // 容易误改
```

**文件 / 目录**：`kebab-case`（多平台安全，避免大小写陷阱）

```text
✅ user-service.js / user-card.jsx
❌ UserService.js / userService.js
```

**私有字段**：`#field`（ES2022 原生），**不要**用 `_field` 假装私有

```js
class Counter {
  #count = 0;                       // ✅ 真私有
  increment() { this.#count++; }
}

// ❌ _count 在外部仍可访问，只是"约定俗成"
class BadCounter {
  constructor() { this._count = 0; }
}
```

**命名"见名知意"**：禁止无意义缩写（`a / tmp / data1 / x`）

```js
// ❌
const d = getData();
const u = fetchUser();

// ✅
const userList = await fetchUser();
const userCount = users.length;
```

**禁用关键字**：`arguments` / `with` / `eval`（参见 [12 §1](./12-JS常见反模式.md)）。

### 1.2 引用与导入（import / export / 路径）

**统一用 ESM**（`import` / `export`），不用 CJS（`require` / `module.exports`）。

```js
// ✅
import { useState } from 'react';
import * as utils from './utils';

// ❌
const React = require('react');
```

**import 排序**：内置 → 第三方 → 内部（各组之间空一行）

```js
// ✅
import fs from 'node:fs';           // 内置（Node 14+ 加 node: 前缀）

import axios from 'axios';           // 第三方
import { z } from 'zod';

import { getUser } from '@/api/user'; // 内部（@/ 是项目别名）
import { formatDate } from './util';
```

**默认导入 vs 具名导入**：**默认具名优先**——避免 `default export` 大对象导致的自动补全失效。

```js
// ❌ 默认导出整个对象
export default { getUser, createUser, deleteUser };

// ✅ 具名导出
export function getUser(id) { /* ... */ }
export function createUser(data) { /* ... */ }
```

**路径别名**：用 `@/` `~/` 引用 `src/`，避免 `../../../` 跨层。

**循环依赖**：禁止 A→B→A。检测工具：`madge`。

### 1.3 类型与解构（const / let / 解构 / 展开）

**禁用 `var`**，只用 `const`（默认）/ `let`（需要重赋值）。

```js
// ✅
const PI = 3.14;
let count = 0;
count++;

// ❌
var PI = 3.14;                      // 变量提升 / 函数级作用域
```

**禁用 `==` / `!=`**，只用 `===` / `!==`。

```js
// ❌
if (count == '5') { /* 隐式转换 */ }

// ✅
if (count === 5) { /* 类型安全 */ }
```

**解构优于字段访问**（多层 / 多次访问时）。

```js
// ✅
const { name, age, address: { city } } = user;
// 使用已解构的 name、age、city 执行既有业务逻辑。

// ❌ 多次 . 链式访问
// user.name、user.age、user.address.city 会重复访问多层属性。
```

**解构 + 默认值** 处理 `undefined`。

```js
const { page = 1, pageSize = 20 } = query;
```

**展开运算符**做浅拷贝（注意：只一层）。

```js
const newUser = { ...user, name: 'bob' };    // ✅ 一层拷贝
const deepCopy = { ...user, address: { ...user.address } };  // 多层要逐层展开
```

### 1.4 字符串与模板（拼接 / 模板字符串 / 标签模板）

**优先模板字符串**，不要 `+` 拼接。

```js
// ✅
const greeting = `Hello, ${name}! You are ${age} years old.`;

// ❌
const greeting = 'Hello, ' + name + '! You are ' + age + ' years old.';
```

**多行字符串**用模板字符串，不要用 `\` 续行。

```js
// ✅
const sql = `
  SELECT *
  FROM users
  WHERE id = ?
`;

// ❌
const sql = 'SELECT *\n' +
             'FROM users\n' +
             'WHERE id = ?';
```

**不要**用 `String()` 隐式转换触发 `toString`，**显式**用 `String(value)` / `Number(value)` / `Boolean(value)`。

### 1.5 函数（声明 / 箭头 / 参数 / 返回值）

**默认用箭头函数**（更简洁、不绑 `this`）。

```js
// ✅
const add = (a, b) => a + b;

// 类方法用普通方法（method）语法
class Counter {
  count = 0;
  increment() { this.count++; }
}
```

**单一职责**：一个函数只做一件事。

```js
// ❌ 一个函数干三件事
function processUser(user) {
  validate(user);
  save(user);
  sendEmail(user);
}

// ✅ 拆开
const validated = validateUser(user);
await saveUser(validated);
await sendWelcomeEmail(validated);
```

**参数 ≤ 3 个**，超过用对象参数。

```js
// ❌ 5 个参数
createUser('alice', 25, 'female', 'alice@example.com', 'Beijing');

// ✅
createUser({ name: 'alice', age: 25, gender: 'female', email: 'alice@example.com', city: 'Beijing' });
```

**纯函数优先**：同样的输入 → 同样的输出，无副作用。

**rest 参数替代 `arguments`**：

```js
// ✅
function sum(...nums) { return nums.reduce((a, b) => a + b, 0); }

// ❌
function sum() { return Array.prototype.reduce.call(arguments, (a, b) => a + b, 0); }
```

### 1.6 类与面向对象（class / 继承 / 私有 / 静态）

**用 `class` 语法**，不用函数构造器。

```js
// ✅
class User {
  constructor(name) { this.name = name; }
  greet() { return `Hi, ${this.name}`; }
}

// ❌ 函数构造器（已过时）
function User(name) {
  this.name = name;
}
User.prototype.greet = function () { return 'Hi, ' + this.name; };
```

**继承 vs 组合**：优先组合（has-a），必须 is-a 才用继承。

```js
// ✅ 组合
class User {
  constructor(name, address) { this.name = name; this.address = address; }
}

// ❌ 过度继承
class BeijingUser extends User { /* 只为继承城市？ */ }
```

**静态方法**用于工具，不依赖实例。

```js
class User {
  static createGuest() { return new User('Guest'); }
}
const guest = User.createGuest();
```

**getter / setter**：仅在字段需要计算 / 校验时使用，简单字段直接公开。

### 1.7 模块化（export / import / 副作用 / 动态导入）

**具名导出为主**。

**barrel files（`index.ts` 重导出）**：谨慎使用——会让 IDE 自动补全变慢、循环依赖风险增加。

```js
// ❌ 一个文件夹下所有模块都在 index 重导出
export * from './user';
export * from './order';
export * from './product';

// ✅ 直接从文件导入
import { getUser } from './user/user.api';
```

**顶层副作用禁止**：模块顶层不要修改全局变量、`window.x = ...`。

**动态 `import()` 用于代码分割**：

```js
// ✅ 路由级懒加载
const Settings = lazy(() => import('./Settings'));

// ✅ 条件加载
if (isDev) {
  const { logger } = await import('./logger');
}
```

### 1.8 控制流（if / switch / for / 异常处理）

**早返回（guard clause）**，减少嵌套。

```js
// ✅ 早返回
function getDiscount(user) {
  if (!user) return 0;
  if (!user.isVip) return 0;
  return user.level === 'gold' ? 0.2 : 0.1;
}

// ❌ 嵌套地狱
function getDiscount(user) {
  if (user) {
    if (user.isVip) {
      if (user.level === 'gold') {
        return 0.2;
      } else {
        return 0.1;
      }
    } else {
      return 0;
    }
  } else {
    return 0;
  }
}
```

**switch 用对象映射替代**（数据驱动）。

```js
// ✅
const STATUS_LABEL = {
  pending: '待处理',
  approved: '已通过',
  rejected: '已拒绝',
};
const label = STATUS_LABEL[status] ?? '未知';

// ❌
let label;
switch (status) {
  case 'pending': label = '待处理'; break;
  case 'approved': label = '已通过'; break;
  case 'rejected': label = '已拒绝'; break;
}
```

**循环选型**：

| 场景 | 推荐 |
|------|------|
| 简单遍历 + 返回新数组 | `map` |
| 过滤 | `filter` |
| 累加 / 折叠 | `reduce`（复杂时拆 for） |
| 仅遍历副作用 | `forEach` |
| 需提前终止 | `for...of` 或 `.find` / `.some` / `.every` |
| 异步迭代 | `for await...of` |

**异常处理**：

- 用 `try/catch` 包可能抛错的代码
- **不要**空 catch / 吞错误

```js
// ❌ 空 catch
try { parseData(input); } catch (e) {}

// ✅ 至少记录 + 重抛
try { parseData(input); }
catch (e) { logger.error('parseData failed', e); throw e; }
```

**自定义错误类**携带业务信息（见 [05-数据访问规则 §2](./05-数据访问规则.md)）。

### 1.9 注释与文档（JSDoc / 行内 / TODO）

**JSDoc** 描述公共 API。

```js
/**
 * 计算两个日期之间相差的天数
 * @param {Date} start - 起始日期
 * @param {Date} end - 结束日期
 * @returns {number} 天数（始终非负）
 * @throws {Error} 当 start/end 不是 Date 实例
 */
function daysBetween(start, end) {
  if (!(start instanceof Date) || !(end instanceof Date)) {
    throw new Error('参数必须是 Date 实例');
  }
  return Math.abs(end - start) / 86_400_000;
}
```

**行内注释解释"为什么"，不解释"是什么"**。

```js
// ❌ 解释是什么（废话）
// 把 count 加 1
count++;

// ✅ 解释为什么
// 用户点击后立即加 1，不等服务端响应（响应失败可回滚）
count++;
```

**TODO / FIXME / XXX 标签**：

```js
// TODO: 待实现 XX 功能
// FIXME: 此处有 bug，需要修复
// XXX: 临时方案，需要重构
```

**自动生成的代码不写注释**（生成器会写）。

## 2. 🟡 推荐 · 团队约定

### 2.1 项目级代码风格细节

详见 [10-代码风格规则](./10-代码风格规则.md)——选择一种（Airbnb / Standard / Google），全项目统一，交给 Prettier 处理。

### 2.2 错误处理统一约定

- 自定义错误类 `BusinessError` / `ValidationError` / `NetworkError`
- 全局 `unhandledrejection` 监听 + 上报
- 见 [05-数据访问规则](./05-数据访问规则.md) 和 [04-异步与事件循环](./04-异步与事件循环.md)

### 2.3 命名补充（缩写词 / i18n 字符串）

**缩写词**全部大写或全部小写（保持一致），不要 `getXMLHttpRequest` 这种混搭。

```js
// ✅ 一致
const API_URL = '...';
function getUser() {}

// ❌ 混搭
const apiUrl = '...';
function getXMLHttpRequest() {}
```

**i18n 字符串**：常量配置或 react-intl 等库，不硬编码。

```js
// ✅
const message = t('user.welcome', { name });

// ❌
const message = '欢迎，' + name;
```

## 3. 🟢 可选 · 视情况

### 3.1 monorepo / 多包项目结构

- 包划分：按业务域 / 按技术层
- 共享代码放 `packages/shared`
- 工具：pnpm workspaces / Turborepo / Nx

### 3.2 国际化（i18n）字符串处理

- 字符串外置到 JSON / YAML
- 模板标签：`html` / `css` 等
- 复杂格式用 ICU MessageFormat
