# 00 - Java Codex 项目入口规则

---

执行 Java 任务前，先阅读 `.ai-rules/java/14-AI通用入口规则.md`，再按 `.ai-rules/java/00-文档总览.md` 读取当前任务相关专题规则。

- 🔴 必须检查构建文件、JDK/框架版本、模块边界、已有依赖、配置和同模块既有实现。
- 🔴 必须只使用项目已验证可用的 API 与依赖；不确定时复用现有实现或询问用户。
- ❌ 禁止臆造依赖、命令、测试结果、接口或项目架构；禁止未经授权升级 JDK/框架、替换构建工具或进行无关重构。
- 🔴 执行与改动相称的现有验证；无法执行时说明原因、未验证范围与风险。

## Java 实现任务的文档影响门禁

- 🔴 任何新增、修改或删除 Java 功能的任务，在开始实现前必须判断技术文档影响。
- 🔴 涉及业务模块、API、数据结构、迁移、鉴权、配置、状态机、生命周期、部署、术语或验证结论变化时，必须读取 `.ai-rules/java-project-docs/其他规则/04-JavaAI技术文档任务入口.md` 和 `.ai-rules/java-project-docs/其他规则/01-技术文档组织与维护规范.md`。
- 🔴 受影响文档未同步时不得报告完整完成；无影响时必须说明结论和依据。
- 🔴 文档规则缺失或路径不存在时必须报告，不能假装已执行。
