# 00 - Python AI 编码规则总览

> 🟢 本规则库适用于 Python 项目的应用代码、库代码、脚本、测试、配置和部署维护。<br>
> 🔴 不适用：将 Django、FastAPI、Flask、SQLAlchemy、pytest、uv 或任何第三方工具当作所有项目的默认前提。

---

## 1. 核心原则

1. 项目的 Python 版本、`pyproject.toml`、锁文件、源码、配置、测试和部署事实优先于本规则库示例。
2. 优先完成最小可验证改动；未经授权不升级 Python、依赖、框架、包管理器或部署方案。
3. 不确定时说明证据缺口或询问用户，不以通用经验补全项目事实。
4. 代码、测试、配置与运行方式共同构成事实来源，不能只根据目录或单个依赖猜测技术栈。

## 2. 规则等级与优先级

| 标识 | 含义 |
|---|---|
| 🔴 | 满足条件时必须遵守；偏离需有项目证据或明确授权 |
| 🟡 | 推荐做法；结合项目现状、性能和成本判断 |
| 🟢 | 可选做法；项目已有采用或用户明确选择时使用 |
| 🟠 | 安全红线；必须优先处理 |

优先级依次为：用户当前任务与安全限制、目标项目约定与事实、[14 - Python AI 通用入口规则](./14-AI通用入口规则.md)、当前任务相关专题规则。
