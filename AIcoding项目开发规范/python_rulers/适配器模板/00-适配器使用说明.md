# 00 - Python AI 编码规则适配器使用说明

---

## 1. 使用目标

本目录为 Codex 与 TRAE 提供 Python 编码规则的薄入口。完整规则只维护在本目录，适配器不得复制专题正文。

## 2. 安装

```text
<python-project>/
├── .ai-rules/python/              # 复制本规则目录的 00、14 与其他规则/
└── AGENTS.md                      # 合并 Codex 入口，不覆盖既有规则
```

- 🔴 Codex：复制规则后，将 `codex/AGENTS.md` 内容合并到项目根 `AGENTS.md`。
- 🔴 TRAE：按 [TRAE 手动使用说明](./trae/00-TRAE手动使用说明.md) 手动附加，不猜测配置路径。
- 🔴 移动 `14-AI通用入口规则.md` 或专题文件时，更新全部适配器路径。
