# 00 - Python AI 编码规则适配器使用说明

---

## 1. 使用目标

本目录提供 Python 规则库的常驻入口。完整执行规则维护在 `python_rulers/` 中；适配器负责触发关键门禁并定位到 [14 - Python AI 通用入口规则](../14-AI通用入口规则.md)。

- 🔴 适配器不得复制整套专题正文。
- 🔴 Codex、Qoder 等自动加载入口必须直接保留简短的文档影响门禁。

## 2. 安装模式

| 模式 | 导入内容 | 能力边界 |
|---|---|---|
| 仅编码模式 | Python 开发规则与当前编辑器入口 | 可开发；发现文档影响时只能报告文档规则缺失 |
| 开发—文档闭环模式（推荐） | Python 开发规则、Python 技术文档规则及两个入口 | 实现任务判断并同步受影响技术文档 |

## 3. 文件映射

| 源内容 | 目标位置 | 说明 |
|---|---|---|
| `AIcoding项目开发规范/python_rulers/00-文档总览.md`、`14-AI通用入口规则.md`、`其他规则/` | `.ai-rules/python/` | Python 开发规则正文 |
| `AIcoding项目文档编写规范/Py项目文档编写规范/其他规则/` | `.ai-rules/python-project-docs/其他规则/` | Python 技术文档规则正文 |
| 两套规则各自的 `适配器模板/codex/AGENTS.md` | 项目根 `AGENTS.md` | 仅 Codex；合并而非覆盖 |
| 开发规则 `python-core.md` 与文档规则 `python-project-docs.md` | `.qoder/rules/` 对应文件 | 仅 Qoder；闭环模式下均设为始终生效 |
| 两套规则各自的 TRAE 使用说明 | 不创建未经验证的固定入口 | 仅 TRAE；按任务手动附加 |

三种编辑器入口三选一，规则正文可以共用。

## 4. 安装与验证

1. 复制规则正文，只安装当前编辑器入口；闭环模式同时安装开发和文档入口。
2. Codex 合并两个 `AGENTS.md`；Qoder 确认两个入口始终生效；TRAE 按说明手动附加。
3. 检查入口引用文件真实存在、入口处于当前项目作用域。
4. 用最小实现任务确认 AI 输出已加载入口、文档影响结论和依据。

## 5. 更新与维护

- 🔴 更新项目根 `AGENTS.md` 时只能合并；移动入口或专题文件后更新全部路径。
- 🔴 Qoder 更新后复核始终生效状态；TRAE 更新后重新附加。
- 🔴 路径、文件名或调用链变化后重新执行文件、编辑器和行为三层验证。
- ❌ 简短门禁只负责触发，不得扩展成第二份完整规则。
