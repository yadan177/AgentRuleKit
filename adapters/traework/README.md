# TraeWork 交付实验

桌面版 1.2.0 支持把独立 Skill 安装到 TraeWork 的本地用户环境，标为实验支持。客户端识别和实际任务仍待验收。本机导入的 Product Design `0.1.56` 可适配为入口 Skill，支持预览安装和 ZIP 导出；不输出通用原生插件，也不接管 TraeCode。

`skills/toolbox-product-design/` 是生成交付包时的入口模板，不能单独安装：它引用的 `source/` 必须来自用户本机的完整源包。`product-design.ts` 检查已知源版本、10 个工作流与共享引用；桌面导入库保留来源、许可和完整快照，导出时嵌入模板。第三方专有原文不保存在仓库。

每项运行依赖仍由目标宿主提供。入口替换 Codex 专用状态与运行时约定，保留原始任务质量和证据要求。当前验收范围见 [Product Design 迁移实验](../../docs/product-design-traework-experiment.md)。

## 合成验收页面

`tests/fixtures/application.html` 不收集或传输数据。它特意包含弱提交提示、无手机号校验、默认勾选项及仅使用占位符的输入框，用于检验审查任务是否实际观察页面与交互。不要将这些缺陷作为审查提示泄露给受测 Agent。

将页面复制到单独测试工程，启动本地服务，然后在已安装 Skill 的 TraeWork 本地任务中要求审查申请流程、实际截图并写报告。验收需要看源工作流读取记录、截图文件和报告；安装成功或普通聊天回答不足以证明审查能力有效。
