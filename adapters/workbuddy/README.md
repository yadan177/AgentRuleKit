# WorkBuddy 项目规则入口

WorkBuddy 的项目级代码开发配置兼容 `AGENTS.md`。选择 WorkBuddy 后，AgentRuleKit 共用一份 `.agent-rules/` 规则和 `AGENTS.md` 受控区块。已有 `.codebuddy/` 配置原地保留。

此入口适用于 WorkBuddy 的本地项目代码开发场景；云端项目指令属于另一套配置，不由本工具写入。

依据：[WorkBuddy 官方项目文档](https://free-plat-test.qcloudcdn.com/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Project)。
