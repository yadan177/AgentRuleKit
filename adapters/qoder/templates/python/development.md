# Python 项目规则入口

先阅读 `.agent-rules/python/14-AI通用入口规则.md`，再按 `.agent-rules/python/00-文档总览.md` 选择当前任务相关专题规则。

- 以 Python 版本、依赖和锁文件、已有代码、配置和 CI 为事实来源；不要把规则示例当成升级或迁移指令。
- 未获授权不得新增依赖、替换框架、修改部署方式或重构无关模块。
- 完成后运行与改动相称的现有验证；不能运行时说明原因、范围和风险。

## Python 实现任务的文档影响门禁

- 任何新增、修改或删除 Python 功能的任务，在开始实现前必须判断技术文档影响。
- 涉及包/业务模块、API、数据模型、迁移、鉴权、配置、任务流程、生命周期、部署、术语或验证结论变化时，必须读取 `.agent-rules/project-docs/python/其他规则/04-PythonAI技术文档任务入口.md` 和 `.agent-rules/project-docs/python/其他规则/01-技术文档组织与维护规范.md`。
- 受影响文档未同步时不得报告完整完成；无影响时必须说明结论和依据。
- 文档规则缺失或路径不存在时必须报告，不能假装已执行。
