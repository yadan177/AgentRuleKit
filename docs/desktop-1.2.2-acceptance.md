# 桌面版 1.2.2 验收

本版修改项目选择方式与下拉控件；安装器兼容范围沿用 [1.2.0 验收记录](desktop-1.2.0-acceptance.md)。

- 本机 92 项测试通过，无失败、无跳过，包含真实 Codex CLI 的隔离生命周期检查；桌面类型检查通过。
- macOS Apple Silicon 安装包构建与资产核对通过；打包后的界面和 Electron 入口文件与当前构建逐文件一致。
- Mac 打包应用的项目下拉框显示“我的项目”中的两个同名临时项目及其不同路径，另一个不可用路径显示为禁用。用户确认实际窗口可以正常展开。
- 键盘确认选择第二个同名项目后，规则安装预览显示该项目的准确路径；通过 Home 切换到第一个项目。End 跳过不可用路径，Esc 取消后保留原选择。
- “插件与技能”的安装目标为同样式自定义菜单，选中标记正确，鼠标可切换至 TraeWork（实验）。更新来源复用该组件；桌面界面源码不包含原生 select／option 控件。
- 在“我的项目”移出全部验证记录后，下拉框同步回到空列表，规则安装按钮不可用。项目登记恢复原状；临时项目文件保持不变，未确认安装规则。

发布前要求当前提交的三系统 CI、双平台安装包构建通过。正式标签必须来自 main，发布后核对两份安装资产与实际摘要。Windows 实机交互、第三方能力实际调用、签名和公证仍待验收。
