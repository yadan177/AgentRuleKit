# 桌面版 1.2.1 验收

本版调整页面结构与界面文字，安装器兼容范围沿用 [1.2.0 验收记录](desktop-1.2.0-acceptance.md)。

- 本机 92 项测试通过，无失败、无跳过，包含真实 Codex CLI 的隔离生命周期检查；桌面类型检查、差异格式检查和现有适配技能的官方校验通过。
- macOS Apple Silicon 安装包构建、资产核对通过；打包界面的脚本与当前源码构建逐文件一致。
- Mac 打包应用默认显示独立“我的项目”页，页面只有项目列表与项目操作。通过临时项目的“管理规则”进入“项目规则”，显示对应路径；移出列表后项目文件保留。
- “插件与技能”页只显示内容库、已安装列表、操作和简短状态；介绍、重复说明及底部说明已删除。“项目规则”页不包含项目列表。
- TraeWork 实验支持以选择项中的“实验”标记表达；具体支持范围和运行验收边界保留在[安装器文档](user-asset-installation.md)。

发布前要求当前提交的三系统 CI、双平台安装包构建通过。正式标签必须来自 main，发布后核对两份安装资产及实际摘要。Windows 实机交互、第三方能力实际调用、签名和公证仍待验收。
