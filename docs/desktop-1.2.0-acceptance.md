# 桌面版 1.2.0 发布候选验收

当前为发布候选，正式版本仍是 1.1.0。仅在发布门槛完成后创建 `desktop-v1.2.0` 标签。

## 已通过

- 本机运行 `AGENTRULEKIT_CODEX_CLI=<已安装的官方 CLI> npm run check`：92 项测试通过，无失败、无跳过。包括真实 Codex CLI 在临时用户环境中的插件安装、更新、缓存漂移拒绝和卸载。
- 桌面 TypeScript 类型检查与 `git diff --check` 通过。
- 适配器 `toolbox-product-design` 使用官方 Skill 格式校验器通过。没有将第三方插件正文打入应用或提交仓库。
- macOS Apple Silicon DMG 构建和安装资产核对通过，应用包版本为 1.2.0。
- 打包后的应用可显示项目页和“插件与 Skills”页。导入选择框改为独立原生对话框，确认按钮可用；旧的附着式选择框在本机验证中无法确认目录。
- 开发版此前通过真实界面的独立 Skill 安装、更新、卸载；只读 Codex `skills/list` 能识别隔离环境中的用户级 Skill。这不是打包应用的完整交互验收。

## 发布前仍需完成

## 明确保留的限制

TraeWork 本地 Skill 为实验支持；客户端识别与实际任务效果未完成验收。Codex 的第三方插件工具连接、Hook 信任和模型实际任务效果仍由目标软件验证。Windows 真实桌面交互、签名、公证、自动中断恢复和新 TRAE 兼容不在本版已验收范围内。
