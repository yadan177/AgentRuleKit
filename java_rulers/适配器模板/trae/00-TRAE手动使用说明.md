# 00 - TRAE 手动使用 Java AI 规则说明

---

## 1. 使用方式

本规则库首期不假设 TRAE 的自动规则文件格式。请在当前 TRAE 版本中手动附加：

1. `.ai-rules/java/14-AI通用入口规则.md`。
2. `.ai-rules/java/00-文档总览.md`。
3. 当前任务需要的专题规则。

## 2. 推荐提示词

```text
先遵守已附加的 Java AI 通用入口规则；检查构建文件、JDK/toolchain、依赖、模块、同模块既有实现和可用验证命令后，再完成当前任务。不要升级 JDK、依赖、框架或基础设施，除非我明确授权。最后报告修改、验证、未验证项与风险。
```

## 3. 后续适配

- 🟡 当 TRAE 官方文档明确项目规则的稳定存储路径和触发方式后，再增加自动加载模板。
- ❌ 在此之前，不猜测或创建未验证的 TRAE 配置文件。
