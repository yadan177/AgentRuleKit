# 00 - Java AI 项目入口规则

---

## 1. 使用要求

将本规则在 Qoder 中设为“始终生效”。执行 Java 任务前，先读取 `.ai-rules/java/14-AI通用入口规则.md`，再按 `.ai-rules/java/00-文档总览.md` 选择专题规则。

## 2. 执行约束

- 🔴 必须检查构建文件、wrapper、JDK/toolchain、依赖、模块、同模块实现、测试和部署配置。
- 🔴 只使用项目已验证可用的 API、依赖与命令；不确定时采用已有实现或询问用户。
- ❌ 禁止臆造配置、数据库对象、依赖、命令、测试结果或项目架构。
- ❌ 禁止未授权升级依赖、迁移框架/基础设施或进行无关重构。
