# 00 - Java AI 规则适配器使用说明

> 🟢 本文件说明如何把 Java 规则库接入 Codex、Cursor、Qoder、TRAE 或其他 AI 工具。
>
> 🔴 不适用：将完整规则复制到多个工具配置中；完整规则只维护一份。

---

## 1. 目标与原则

本目录提供的是**薄入口模板**，不是四份完整规则副本。

- 🔴 先将 `java_rulers/` 复制到目标 Java 项目的 `.ai-rules/java/`，保留文件层级。
- 🔴 只复制当前实际使用的 AI 工具对应模板到目标项目根目录。
- 🟡 推荐将 `.ai-rules/java/` 和选用的规则配置一并纳入项目版本控制。

## 2. 目标项目目录

```text
<java-project>/
├── .ai-rules/
│   └── java/
│       ├── 00-文档总览.md
│       ├── 14-AI通用入口规则.md
│       └── 其他规则/
├── AGENTS.md                       # 仅 Codex 模板需要
├── .cursor/rules/java-core.mdc     # 仅 Cursor 模板需要
└── .qoder/rules/java-core.md       # 仅 Qoder 模板需要
```

## 3. 安装方式

### 3.1 Codex

将 `codex/AGENTS.md` 复制到目标项目根目录。Codex 会从项目根目录向当前目录读取 `AGENTS.md`；入口只加载通用规则，再按任务定位专题文档。

### 3.2 Cursor

将 `cursor/.cursor/` 复制到目标项目根目录。`java-core.mdc` 只包含 Cursor frontmatter 和短入口指令，不复制完整规则内容。

### 3.3 Qoder

将 `qoder/.qoder/` 复制到目标项目根目录。在 Qoder 的“规则”设置中将 `java-core` 设为“始终生效”。Qoder 的规则文件位于 `.qoder/rules/*.md`。

### 3.4 TRAE 与其他 AI 工具

参见 `trae/00-TRAE手动使用说明.md`。在未确认工具的项目规则格式前，手动附加 14 号规则与当前任务需要的专题规则。

## 4. 维护要求

- 🔴 `.ai-rules/java/` 是唯一完整规则来源。
- 🔴 修改 14 号规则后，检查三个薄入口是否仍能定位到它。
- ❌ 不得在适配器中复制整套专题规则，避免多份内容漂移。
