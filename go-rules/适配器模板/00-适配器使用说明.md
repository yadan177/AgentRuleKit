# 00 - Go AI 规则适配器使用说明

---

## 1. 目标与原则

本目录提供将 Go 规则库接入 Codex、Qoder 与 TRAE 的**薄入口**。完整规则只维护在 `go-rules/` 中，适配器只负责让对应工具定位到 [13 - Go AI 通用入口规则](../13-AI通用入口规则.md)。

- 🔴 **必须**保留 `go-rules/` 的现有目录和专题文档；适配器不得复制整套正文。
- 🔴 **必须**在目标项目中让入口能定位到规则库和所需专题文档。
- 🟡 推荐将规则库与实际使用的入口配置一并纳入版本控制。

## 2. 目标项目结构

```text
<go-project>/
├── .ai-rules/go/                 # 完整复制 go-rules/
├── AGENTS.md                     # Codex 入口
└── .qoder/rules/go-core.md       # Qoder 入口
```

## 3. 安装方式

### 3.1 Codex

将整个 `go-rules/` 复制到目标项目 `.ai-rules/go/`，再将 `codex/AGENTS.md` 复制到目标项目根目录。

### 3.2 Qoder

将整个 `go-rules/` 复制到目标项目 `.ai-rules/go/`，再将 `qoder/.qoder/` 复制到目标项目根目录，并在 Qoder 中将 `go-core` 设为始终生效。

### 3.3 TRAE

将整个 `go-rules/` 复制到目标项目 `.ai-rules/go/`。未核实当前 TRAE 版本的稳定项目规则存储格式前，按 [TRAE 手动使用 Go AI 规则说明](./trae/00-TRAE手动使用说明.md) 手动附加入口，不猜测配置路径。

## 4. 维护要求

- 🔴 修改 13 号通用入口后，必须检查三个适配器仍能定位到它。
- 🔴 移动或改名专题文档后，必须更新总览和适配器中的链接。
- ❌ 禁止在多个适配器中复制完整专题规则，造成多份内容漂移。
