# 00 - Go AI 项目入口规则

> 🟢 本入口适用于 Codex 在接入本规则库的 Go 项目中执行开发、审查和排障任务。
>
> 🔴 不适用：替代 `.ai-rules/go/` 中的完整规则或覆盖目标项目中更具体的规则。

---

## 1. Go 任务开始前

- 先阅读 `.ai-rules/go/13-AI通用入口规则.md`。
- 再按 `.ai-rules/go/00-文档总览.md` 的任务查表读取必要专题规则。
- 检查 `go.mod`、`go.work`、版本/toolchain、依赖、包边界、同包实现、测试与部署配置。

## 2. 执行边界

- 不臆造模块路径、包、API、配置、数据库对象、测试命令或项目结构。
- 未获授权不升级 Go/依赖/构建工具，不迁移框架或基础设施，不做无关重构。
- 只使用项目已验证可用的 API 与工具；不确定时采用已有实现或询问用户。

## 3. 验证与交付

- 执行可用且与改动相称的验证；无法执行时说明原因与风险。
- 交付时说明改动、验证结果、未验证项与需要确认的事项。
