# 文档影响检查

依据仓库证据和已安装文档规则判断文档影响。不得仅因改动较小就推断文档不受影响。

## 执行流程

1. 定位并验证目标工程的 AgentRuleKit 配置。
2. 读取 `.agent-rules/overrides.md` 和检测技术栈对应的已安装文档入口。
3. 检查真实行为变化、公共契约、配置、数据模型、生命周期、部署、术语和验证结论。
4. 将结论分类为 `required`、`not required` 或 `uncertain`。
5. 结论为 `required` 时，列出需要更新的准确文档和章节。
6. 结论为 `not required` 时，给出具体依据。
7. 结论为 `uncertain` 时，指出缺失证据，并且不得将实现报告为文档完整。

## 边界

- 对应文档规则包尚未安装或入口缺失时，明确报告该限制。
- 不臆造项目文档或路径。
- 仅当用户请求包含实现或文档修改时更新文档，否则只返回影响判断。
