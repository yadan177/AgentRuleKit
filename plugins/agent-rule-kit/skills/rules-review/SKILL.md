# 规则审查

只依据目标工程实际安装且与当前变更相关的规则执行审查。

## 执行流程

1. 从目标工程根目录定位 `agent-rules.yaml`、`.agent-rules.lock.json` 和 `.agent-rules/overrides.md`。
2. 在依赖受管文件前运行 `agent-rule check <project-root>`。
3. 读取项目覆盖规则，以及与任务直接相关的已安装规则入口和专题。
4. 检查请求范围内的代码、测试、配置和仓库证据。
5. 优先报告问题，按严重程度排序，并提供准确文件引用和具体影响。
6. 区分确定违反的规则、改进建议和仍缺少证据的问题。
7. 说明实际使用了哪些规则包和规则文件。

## 边界

- manifest 仍为 `scaffolded` 或文件缺失时，不得声称工程符合该规则包。
- 项目事实和用户当前要求的优先级高于共享建议。
- 用户未同时要求修复时，审查过程中不修改代码。
