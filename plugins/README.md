# 场景能力插件资产目录

这里预留给 AI 开发工具箱自己的能力插件，不是工具箱应用的安装包，也不是某个 IDE 的插件市场根目录。一个能力插件可以声明所需 Skills、工具和规则类别；规则正文始终只从 `rulepacks/` 读取。

当前没有可安装的场景能力插件。[`asset.schema.json`](../schemas/asset.schema.json) 只覆盖身份、版本和基础依赖；真实资产还需要约定内容来源与交付文件、任务输入输出、工具权限、共享 Skill 的归属，以及项目启用方式。首个插件开发时应补齐这些契约，经目标 IDE 适配器完成实际安装与调用验收后，才能在工具箱中显示为可安装。
